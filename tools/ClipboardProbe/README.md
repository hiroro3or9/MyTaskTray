# ClipboardProbe

`DESIGN_RICH_COPY.md` の §9「Windows 実機で確認が必要なこと」を手で試すためのツール。

本体には手を入れずに、**判断に必要な事実だけを先に集める**のが目的。
ここで分かったことを設計メモへ書き戻してから、本体の実装に入る。

`MyTaskTray.slnx` には**入れていない**。本体のビルドに影響させないため。
Visual Studio で開きたければ後から足してよい。

## 実行

```
cd tools\ClipboardProbe
dotnet run
```

起動すると、まずクリップボードに触らずに CF_HTML の自己検査だけを行う。

```
[起動時の自己検査] ヘッダのオフセットで正しく切り出せるか
  バイト数で計算 : OK: 全長 321 バイト / Fragment 156 バイト
  文字数で計算   : NG: Fragment がずれている -> 「…<strong>高</strong>?」
```

**下が NG になるのが期待どおり。** これが両方 OK になるなら、
確認用の断片から日本語が抜けている（§4-1 の主張が再現できていない）。

## メニューと確認項目の対応

| | やること | 設計メモ | 見るところ |
| --- | --- | --- | --- |
| 1 | CF_HTML を `string` で渡して載せる | §9-1 | Word に貼って日本語が化けないか |
| 2 | CF_HTML を UTF-8 バイト列で渡して載せる | §9-1 | 同上。1 と 2 のどちらが通るか |
| 3 | わざと文字数で数えた CF_HTML を載せる | §4-1 | **貼れないこと**を確かめる（裏取り） |
| 4 | TSV と HTML を同時に載せる | §9-3 | Excel でセルに割れるか、1 セルに収まるか |
| 5 | いま載っている形式を一覧する | §9-2 | 形式名・型・大きさ・読み取り時間 |
| 6 | 形式の中身をファイルへ書き出す | §9-2/5/6 | `%TEMP%\ClipboardProbe\` の `index.txt` |
| 7 | 捕まえて → クリア → 復元 | §9-9 | 元のアプリに貼って書式が戻るか |
| 8 | 1 つの形式を 4 通りの方法で読み比べる | §6-9 | **`HTML Format` が null になる件の切り分け** |
| 9 | CF_HTML を載せる（バイト列 + NUL 終端） | §4-3 | 読み戻しが 1 バイト欠けなくなるか |

## 分かったこと

- **§4-3 は決着。** `string` で渡すのが正しい。.NET が UTF-8 で書き、NUL 終端も付ける。
  バイト列で渡すと終端が付かず、読み戻しで末尾 1 バイトが落ちる
- **自分で載せた CF_HTML は 4 経路すべてで読める。** 出力側は健全

## いま残っている確認

### 1. Excel の `HTML Format` を Win32 で読めるか

Excel で範囲をコピーしてから `8` → Enter。**これが最後の未解決事項です。**

| Win32 直読みの結果 | 意味 | 本体の実装 |
| --- | --- | --- |
| 読める | データはある。.NET の包み方が問題 | `RawClipboard.cs` をそのまま使う |
| 読めない | Excel が実体を渡していない | HTML は諦め、RTF と XML Spreadsheet で代替 |

### 2. Word へ実際に貼ったときの見た目

`1` で載せてから Word に貼り、見出しと箇条書きになるか、日本語が化けないか。
あわせて `3`（わざと壊した版）でも貼って、**壊れることを確かめる**。
両方きれいに貼れてしまうなら、Word が寛容なだけで何も検証できていません。

### 3. NUL 終端の裏取り（任意）

`9` で載せてから `8` で読み戻し、WPF 側が 320 B ではなく 321 B になれば仮説どおりです。

## 特に見てほしいこと

### 1 と 2 のどちらが通るか（§4-3 の未決事項）

`string` で渡す形が通るなら、本体のコードは簡単になる。
通らない、または日本語だけ化けるなら、バイト列で渡す形に決まる。
**どちらも通る場合はバイト列を選ぶ**（.NET の実装に依存しないため）。

### 5 を Excel で実行する（§9-2 の出発点）

Excel で適当な範囲をコピーしてから `5` を選ぶと、20 個以上の形式が並ぶはず。
**「未分類」に出たものが、許可リストに足すかどうかの検討対象**になる。

読み取り時間の合計も出る。ここが数秒かかるようなら、
本体では捕獲中に UI を止めない作りが要る（§6-4）。

### 5 をコピー元アプリを閉じてから実行する（§9-5）

Excel でコピー → Excel を終了 → `5` を選ぶ。
遅延レンダリングの形式が `null` を返すのか例外になるのかで、失敗の扱い方が変わる。

### 5 をパスワード管理ソフトからのコピーで実行する（§9-7）

保存を禁じる印が載っていれば、一覧を出さずに中止する。
**中止されずに一覧が出てしまう場合、印の名前が想定と違う**ということなので、
`FormatCatalog.ExclusionMarkers` を直す必要がある。

| ファイル | 中身 |

| `CfHtml.cs` | CF_HTML の組み立て。**本体へそのまま持っていく実装候補** |

`CfHtml.cs` と `FormatCatalog.cs` は、確認が済んだら本体の `Services` へ移す前提で書いてある。
`Program.cs` は捨てる。
