# MyTaskTray

タスクトレイに常駐し、右クリックメニューから選んだ文字列をクリップボードにコピーする Windows 常駐ツールです。

## 使い方

1. ビルドして実行すると、ウィンドウは開かずタスクトレイにアイコンが表示されます。
2. トレイアイコンを **左クリック または 右クリック** するとコピー項目の一覧が出ます。クリックすると、その項目の文字列がクリップボードにコピーされます。
3. コピーすると画面右下に小さな通知が出ます（設定画面でオフにできます）。
4. 設定画面はメニュー →「設定...」から開きます。
5. 終了はメニュー →「終了」。

見た目は Windows の外観設定（ライト / ダーク、アクセント色）に自動で合わせます。設定を変更すると、起動したまま切り替わります。

## 設定画面

左が項目の一覧、右が選択した項目の編集欄です。一覧は 1 行目に表示名、2 行目にコピーされる文字列、右端にカテゴリと連番のバッジが出ます。

| 操作 | 説明 |
| --- | --- |
| 検索 | 表示名・コピー文字列・カテゴリで絞り込みます（絞り込み中は並べ替えできません） |
| 追加 | 新しいコピー項目を選択位置の下に追加します |
| 区切り線 | メニューに水平線を入れます（グループの区切り用） |
| 複製 | 選択項目をコピーします |
| 削除 | 選択項目を削除します（中身のある項目は確認します） |
| ▲ / ▼ | 並び替えます。**リストの順序がそのままメニューの順序** になります |
| 行のドラッグ | ▲▼ と同じ並べ替えです。挿入位置が線で表示されます |
| コピーして試す | プレビューの内容をそのままコピーします（連番は進みません） |

保存せずに閉じようとすると、保存するかどうかを確認します。

### ショートカット

| キー | 動作 |
| --- | --- |
| Ctrl+F | 検索欄へ移動 |
| Ctrl+N | 項目を追加 |
| Ctrl+D | 選択項目を複製 |
| Alt+↑ / Alt+↓ | 選択項目を上下に移動（入力欄にカーソルがあるときは無効） |
| Delete | 一覧で選択中の項目を削除 |
| Ctrl+S | 保存して閉じる |
| Esc | キャンセル（ポップアップが開いているときは閉じる） |

### カテゴリ（サブメニュー）

「カテゴリ」に名前を入れると、その名前のサブメニュー配下にまとまります。空欄ならトップレベルに表示されます。
同じカテゴリ名の項目は、最初にそのカテゴリが登場した位置のサブメニューにまとめられます。
入力欄の右の「▾」から、すでに使っているカテゴリを選べます。

## 差し込み（日付などの計算値）

コピー文字列には `{...}` 形式の差し込みを書けます。コピーした瞬間に評価されるので、固定文と混ぜて使えます。

```
{date:yyyy/MM/dd} 定例ミーティング 議事録
→ 2026/07/30 定例ミーティング 議事録
```

設定画面の「差し込みを挿入 ▾」を押すと、クリップボード / 日付 / 時刻 / 月・週 / 計算 / 日付の数値 / 連番・その他のグループに分かれた一覧が開きます。
各行には**いま挿入した場合の値**が並ぶので、書式を確かめてから選べます。上の欄でキーワード検索もできます。
選ぶとカーソル位置に挿入され、下部のプレビューで実際にコピーされる文字列を確認できます。

### 書式

```
{名前[±数値[単位]][:書式]}
{calc:式[|数値の書式]}
```

- 書式は .NET の書式指定文字列。日付なら `yyyy/MM/dd`、`yyyy年M月d日`、`ddd`（曜日）など
- 単位は `d` 日 / `w` 週 / `mo` 月 / `y` 年 / `h` 時 / `mi` 分 / `s` 秒。省略時は日（`{time}` のみ分）
- `{{` と `}}` はそれぞれ `{` `}` そのものを表す
- 解釈できない差し込みは、書いたままの文字列が残るので誤りに気付けます。
  未知の名前だけでなく、**単位の書き間違い**（月は `m` ではなく `mo`、分は `min` ではなく `mi`）や、
  オフセットを付けられない差し込み（`{guid+1}` など）も同様に展開されずそのまま残ります

### 一覧

| 差し込み | 内容 | 例 |
| --- | --- | --- |
| `{clip}` | いまコピーしてある文字列（前後の空白は除く） | `4329` |
| `{clip:digits}` | 最初の数字だけを取り出す | `4329` |
| `{clip:/ID-(\d+)/}` | 正規表現で取り出す（かっこがあればその中身） | `4329` |
| `{clip:line}` | 1 行目だけ | |
| `{clip:upper}` / `{clip:lower}` | 大文字 / 小文字にする | |
| `{clip:raw}` | 空白・改行も含めてそのまま | |
| `{date}` | 今日の日付 | `2026/07/30` |
| `{date:yyyyMMdd}` | 書式を指定した日付 | `20260730` |
| `{date+1}` / `{date-1}` | 明日 / 昨日 | `2026/07/31` |
| `{date+1w}` `{date+2mo}` `{date-1y}` | 週・月・年の加減算 | `2026/08/06` |
| `{time}` | 現在の時刻 | `14:05` |
| `{time:HH:mm:ss}` | 秒まで含む時刻 | `14:05:32` |
| `{time+30}` | 30 分後 | `14:35` |
| `{datetime}` | 日付と時刻 | `2026/07/30 14:05` |
| `{monthstart}` / `{monthend}` | 今月の初日 / 末日 | `2026/07/01` / `2026/07/31` |
| `{monthend+1}` | 翌月の末日 | `2026/08/31` |
| `{weekstart}` / `{weekend}` | 今週の月曜 / 日曜 | `2026/07/27` / `2026/08/02` |
| `{seq}` | 連番（コピーごとに増える） | `7` |
| `{seq:0000}` | 桁を揃えた連番 | `0007` |
| `{seq+1}` | 次の番号 + 1（範囲を書くときなど） | `8` |
| `{guid}` | GUID（小文字・ハイフンあり） | `3f2a…` |
| `{guid:N}` `{guid:B}` `{guid:U}` | ハイフンなし / 波かっこ付き / 大文字 | |
| `{random}` / `{random:1-6}` | 乱数（既定は 1〜100） | `42` |
| `{year}` `{month}` `{day}` | 年 / 月 / 日を数値で | `2026` `7` `30` |
| `{month:00}` | 桁を揃えた月 | `07` |
| `{hour}` `{minute}` `{second}` | 時 / 分 / 秒を数値で | `14` `5` `32` |
| `{dow}` | 曜日番号（月曜=1 〜 日曜=7） | `4` |
| `{week}` / `{doy}` | ISO 週番号 / 元日からの通日 | `31` / `211` |
| `{daysinmonth}` | 今月の日数 | `31` |
| `{daysuntil:2026-12-31}` | 指定日までの日数（過去なら負） | `154` |
| `{calc:式}` / `{=式}` | 計算式（下記） | `{calc:1+2}` → `3` |

日付の数値は `{year+1}` のようにオフセットも書けます（単位の既定は名前に合わせて年・月・日…）。

## クリップボードの内容を差し込む

決まった形のうち一部だけが毎回変わる文字列は、変わる部分を `{clip}` にしておきます。

```
feature/AAA/ver1.0.0/ID-{clip}
```

1. 変わる部分（`4329`）を、チケット画面などからいつもどおりコピーする
2. トレイメニューからこの項目を選ぶ
3. `feature/AAA/ver1.0.0/ID-4329` がクリップボードに入る

貼り付け先で文字列を組み立てる必要がなくなり、操作は「コピー → クリック」だけになります。
メニューのツールチップには展開後の値が出るので、選ぶ前に結果を確認できます。

### 余計な文字を取り除く

コピー元に他の文字が混ざっていても、必要な部分だけを取り出せます。

```
クリップボード: ID-4329 ログイン画面が表示されない

feature/AAA/ver1.0.0/ID-{clip:digits}      → feature/AAA/ver1.0.0/ID-4329
feature/AAA/ver1.0.0/{clip:/ID-\d+/}       → feature/AAA/ver1.0.0/ID-4329
{clip:line}                                 → ID-4329 ログイン画面が表示されない
```

`digits` `line` `upper` `lower` `raw` `trim` 以外の書式は**正規表現**として扱い、最初に一致した部分を取り出します。
`ID-(\d+)` のようにかっこ（キャプチャ）を書くと、その中身だけが差し込まれます。
一致しなかった場合は `{clip:…}` と書いたままの文字列が残るので、意図しない結果に気付けます。

`{clip}` を含む項目を選んだときにクリップボードが空だと、コピーは行わず通知でお知らせします。
数値であれば `{calc:{clip}*1.1|#,##0}` のように計算式の中でも使えます。

## 計算式

`{calc:式}`（短く `{=式}`）でコピーする瞬間に計算します。`|` のうしろに .NET の数値書式を書けます。

```
小計 {calc:1200*3|#,##0} 円 / 消費税 {calc:1200*3*10%|#,##0} 円 / 合計 {calc:1200*3*1.1|#,##0} 円
→ 小計 3,600 円 / 消費税 360 円 / 合計 3,960 円
```

### 書ける記法

| 種類 | 内容 |
| --- | --- |
| 数値 | `1` `1.5` `1_000_000`（`_` は桁区切り。カンマは引数の区切りなので使えません） |
| 演算子 | `+` `-` `*` `/` `^`（べき乗）、単項の `-`、`×` `÷` も可 |
| べき乗の優先順位 | 単項の `-` が `^` より強いため `-2^2` は `4`（Excel と同じ）。`-(2^2)` はかっこで書く |
| 後置 `%` | `8%` は `0.08`。`1200*10%` で消費税額 |
| かっこ | `(` `)`（何重でも） |
| 定数 | `pi` `e` |
| 丸め | `round(x[,桁])`（四捨五入）`floor` `ceil` `trunc` |
| 数学 | `abs` `sign` `sqrt` `pow(x,y)` `mod(a,b)` `log(x[,底])` `log10` `exp` |
| 集計 | `min(...)` `max(...)` `sum(...)` `avg(...)`（引数はいくつでも） |

- 計算は `decimal` で行うので、`0.1+0.2` は `0.3` になります（金額の計算で誤差が出ません）
- 書式を省略した場合は小数 10 桁までで、末尾の 0 は付きません（`2` / `1.5` / `0.3333333333`）
- 式が誤っていれば `{calc:…}` と書いたままが残るので、プレビューで気付けます

### 式の中で差し込みを使う

式の中には他の差し込みを書けます。連番や日付の数値と組み合わせると便利です。

```
請求書番号 {calc:{seq}*10|0000}      → 連番 7 なら 0070
納期まであと {calc:{daysuntil:2026-12-31}/7|0} 週
今月は {calc:{daysinmonth}-{day}} 日残っています
```

式の中で使えるのは**数値になる差し込み**だけです。`{date}`（`2026/07/30`）や `{guid}` のような
文字列の差し込みを書いた場合は計算せず、`{calc:…}` と書いたままの文字列が残ります。
`{year}` `{month}` `{day}` `{seq}` `{daysuntil:…}` などの数値の差し込み、または
`{date:yyyyMMdd}` のように数値だけになる書式を指定してください。

### 連番について

`{seq}` を含む項目には設定画面に「連番の設定」が表示され、**次の番号**と**増分**を指定できます。
コピーするたびに番号が進み、`settings.json` に保存されます。
増分に負の値を入れるとカウントダウンになります。

`{{seq}}` のようにエスケープした場合はリテラルの文字列 `{seq}` になるため、番号は進みません。

> 設定画面を開いている間にトレイからコピーして番号が進んだ場合も、保存時に `Id` で突き合わせて
> 進んだ番号を引き継ぎます。画面で「次の番号」を直接編集したときは、そちらの値が優先されます。

## 設定ファイル

`%APPDATA%\MyTaskTray\settings.json`

設定画面の左下「設定フォルダーを開く」で場所を開けます。手で編集することもできます。

```json
{
  "Version": 1,
  "ShowCopyNotification": true,
  "Items": [
    {
      "Id": "a1b2c3d4e5f60718293a4b5c6d7e8f90",
      "Name": "メールアドレス",
      "Text": "example@example.com",
      "Category": "",
      "IsSeparator": false,
      "SequenceValue": 1,
      "SequenceStep": 1
    },
    { "Name": "", "Text": "", "Category": "", "IsSeparator": true },
    { "Name": "今日", "Text": "{date:yyyy/MM/dd}", "Category": "日付", "IsSeparator": false }
  ]
}
```

| フィールド | 意味 |
| --- | --- |
| `ShowCopyNotification` | コピー時に画面右下へ通知を出すか（既定は `true`） |
| `Id` | 項目の識別子（自動生成。連番の引き継ぎに使用） |
| `Name` | メニューに表示する名前（空ならコピー文字列を表示） |
| `Text` | クリップボードにコピーする文字列（改行・差し込み可） |
| `Category` | サブメニュー名。空ならトップレベル |
| `IsSeparator` | `true` で区切り線として表示 |
| `SequenceValue` | `{seq}` が次に出力する番号 |
| `SequenceStep` | 連番の増分 |

ファイルが壊れていた場合は `settings.json.bak` に退避され、既定値で起動します。

## 仕様メモ

- 二重起動は Mutex で防止します。
- トレイアイコンは `Resources/app.ico` を使用します。
- クリップボードが他プロセスにロックされている場合、最大 5 回まで再試行します。
- 配色は `AppsUseLightTheme` と DWM の `AccentColor` をレジストリから読み、Windows の設定変更に追従します。
  アクセント色が背景に対して読みにくい場合は明るさを補正します。
- コピー通知はフォーカスを奪わずに表示し、約 1.8 秒で消えます（クリックでも消えます）。


### アイコン

墨色のタイルに白のカギ括弧「」を置いています。「あらかじめ用意された言葉」を道具ではなく言葉そのもので表す意図なので、
**中央の余白には何も足さない**でください。

16 / 20 / 24 / 32px は SVG の縮小ではなく `tools/make-icon.py` の中でピクセル単位に描き分けています
（縮小すると 2px の線が半端な位置に乗ってにじむため）。デザインを変えたら次を実行して `Resources/app.ico` を作り直します。

```
pip install cairosvg pillow
python tools/make-icon.py Resources/app-icon.svg Resources/app.ico
```
