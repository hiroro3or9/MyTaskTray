# MyTaskTray

タスクトレイに常駐し、右クリックメニューから選んだ文字列をクリップボードにコピーする Windows 常駐ツールです。

## 使い方

1. ビルドして実行すると、ウィンドウは開かずタスクトレイにアイコンが表示されます。
2. トレイアイコンを **左クリック または 右クリック** するとコピー項目の一覧が出ます。クリックすると、その項目の文字列がクリップボードにコピーされます。
3. コピーすると画面右下に小さな通知が出ます（設定画面でオフにできます）。
4. 設定画面はメニュー →「設定...」から開きます。
5. 終了はメニュー →「終了」。

見た目は Windows の外観設定（ライト / ダーク、アクセント色）に自動で合わせます。設定を変更すると、起動したまま切り替わります。

## 設定画面

左が項目の一覧、右が選択した項目の編集欄です。一覧は 1 行目に表示名、2 行目にコピーされる文字列、右端にカテゴリと連番のバッジが出ます。

| 操作 | 説明 |
| --- | --- |
| 検索 | 表示名・コピー文字列・カテゴリで絞り込みます（絞り込み中は並べ替えできません） |
| 追加 | 新しいコピー項目を選択位置の下に追加します |
| 区切り線 | メニューに水平線を入れます（グループの区切り用） |
| 複製 | 選択項目をコピーします |
| 削除 | 選択項目を削除します（中身のある項目は確認します） |
| ▲ / ▼ | 並び替えます。**リストの順序がそのままメニューの順序** になります |
| 行のドラッグ | ▲▼ と同じ並べ替えです。挿入位置が線で表示されます |
| コピーして試す | プレビューの内容をそのままコピーします（連番は進みません） |

保存せずに閉じようとすると、保存するかどうかを確認します。

### ショートカット

| キー | 動作 |
| --- | --- |
| Ctrl+F | 検索欄へ移動 |
| Ctrl+N | 項目を追加 |
| Ctrl+D | 選択項目を複製 |
| Alt+↑ / Alt+↓ | 選択項目を上下に移動（入力欄にカーソルがあるときは無効） |
| Delete | 一覧で選択中の項目を削除 |
| Ctrl+S | 保存して閉じる |
| Esc | キャンセル（ポップアップが開いているときは閉じる） |

### カテゴリ（サブメニュー）

「カテゴリ」に名前を入れると、その名前のサブメニュー配下にまとまります。空欄ならトップレベルに表示されます。
同じカテゴリ名の項目は、最初にそのカテゴリが登場した位置のサブメニューにまとめられます。
入力欄の右の「▾」から、すでに使っているカテゴリを選べます。

## 差し込み（日付などの計算値）

コピー文字列には `{...}` 形式の差し込みを書けます。コピーした瞬間に評価されるので、固定文と混ぜて使えます。

```
{date:yyyy/MM/dd} 定例ミーティング 議事録
→ 2026/07/30 定例ミーティング 議事録
```

設定画面の「差し込みを挿入 ▾」を押すと、クリップボード / 日付 / 時刻 / スプリント / 月・週 / 計算 / 日付の数値 / 連番・その他のグループに分かれた一覧が開きます。
各行には**いま挿入した場合の値**が並ぶので、書式を確かめてから選べます。上の欄でキーワード検索もできます。
選ぶとカーソル位置に挿入され、下部のプレビューで実際にコピーされる文字列を確認できます。

プレビューは `{time}` などを含むときだけ 1 秒ごとに更新します。
`{clip}` の値は、他のアプリでコピーしてから設定画面に戻ってきたタイミングで読み直します
（入力のたびにクリップボードを開くと、他アプリのコピー操作を妨げるため）。

### 書式

```
{名前[@基準][±数値[単位]]…[:書式]}
{calc:式[|数値の書式]}
```

- 書式は .NET の書式指定文字列。日付なら `yyyy/MM/dd`、`yyyy年M月d日`、`ddd`（曜日）など
- **基準**は、日付を今日以外から数え始めたいときに書きます

  | 基準 | 起点 |
  | --- | --- |
  | `@sprint` | 今日を含むスプリントの開始日（→ [スプリント](#スプリント)） |
  | `@clip` | クリップボードに入っている日付（→ [クリップボードの日付](#クリップボードの日付)） |
  | `@date` `@monthstart` `@monthend` `@weekstart` `@weekend` | 同じ名前の差し込みと同じ日 |

  基準そのものにオフセットは書けません。`{year@sprint-3mo}` の `-3mo` は**結果のほう**に掛かります
- 単位は `d` 日 / `w` 週 / `mo` 月 / `y` 年 / `h` 時 / `mi` 分 / `s` 秒 / `sp` スプリント。
  省略時は差し込みの名前に合わせた単位になります

  | 省略時の単位 | 差し込み |
  | --- | --- |
  | 日 | `{date}` `{datetime}` `{day}` `{dow}` `{doy}` |
  | 週 | `{weekstart}` `{weekend}` `{week}` |
  | 月 | `{monthstart}` `{monthend}` `{month}` `{daysinmonth}` |
  | 年 | `{year}` |
  | 時 | `{hour}` |
  | 分 | `{time}` `{minute}` |
  | 秒 | `{second}` |

- **オフセットは重ねて書けます**。書いた順に適用されます

  ```
  {date+1mo-1}          翌月の前日
  {date@sprint+1sp-1}   今のスプリントの最終日
  {date@sprint+2sp-1}   次のスプリントの最終日
  ```

  ただし `{monthstart}` `{monthend}` `{weekstart}` `{weekend}` は
  **オフセットを適用したあとに**月初・月末・週初・週末を求めます。
  `{monthstart+1mo-1}` は「翌月の前日を含む月の初日」＝今月の初日であって、月末ではありません
  （月末は `{monthend}`）
- 数値は、書式を指定しなければ地域設定に左右されない表記、
  書式を指定した場合は桁区切りなどが地域設定に従います（`{seq}` `{month}` `{calc:…}` で共通）
- `{{` と `}}` はそれぞれ `{` `}` そのものを表す
- 解釈できない差し込みは、書いたままの文字列が残るので誤りに気付けます。
  未知の名前だけでなく、**単位の書き間違い**（月は `m` ではなく `mo`、分は `min` ではなく `mi`）や、
  オフセットを付けられない差し込み（`{guid+1}` `{random+5}` `{daysuntil+1:…}` など）も
  同様に展開されずそのまま残ります

## クリップボードの内容を差し込む

決まった形のうち一部だけが毎回変わる文字列は、変わる部分を `{clip}` にしておきます。

```
feature/AAA/ver1.0.0/ID-{clip}
```

1. 変わる部分（`4329`）を、チケット画面などからいつもどおりコピーする
2. トレイメニューからこの項目を選ぶ
3. `feature/AAA/ver1.0.0/ID-4329` がクリップボードに入る

貼り付け先で文字列を組み立てる必要がなくなり、操作は「コピー → クリック」だけになります。
メニューのツールチップには展開後の値が出るので、選ぶ前に結果を確認できます。

### 余計な文字を取り除く

コピー元に他の文字が混ざっていても、必要な部分だけを取り出せます。

```
クリップボード: ID-4329 ログイン画面が表示されない

feature/AAA/ver1.0.0/ID-{clip:digits}      → feature/AAA/ver1.0.0/ID-4329
feature/AAA/ver1.0.0/{clip:/ID-\d+/}       → feature/AAA/ver1.0.0/ID-4329
{clip:line}                                 → ID-4329 ログイン画面が表示されない
```

`digits` `line` `upper` `lower` `raw` `trim` 以外の書式は**正規表現**として扱い、最初に一致した部分を取り出します。
`ID-(\d+)` のようにかっこ（キャプチャ）を書くと、その中身だけが差し込まれます。
一致しなかった場合は `{clip:…}` と書いたままの文字列が残るので、意図しない結果に気付けます。

### クリップボードの日付

差し込みに `@clip` と書くと、**クリップボードの文字列を日付として読んで**起点にします。
日付をコピーしてメニューを選ぶだけで、書式の変換や前後の日付の計算ができます。

```
クリップボード: 2026/08/15

{date@clip:yyyyMMdd}       → 20260815
{date@clip:yyyy年M月d日}     → 2026年8月15日
{date@clip:ddd}            → 土
{date@clip+1w}             → 2026/08/22
{date@clip+1mo-1}          → 2026/09/14
{week@clip} {dow@clip}     → 33  6
```

`{month@clip}` `{year@clip}` `{monthend@clip}` など、日付から作られる差し込みはすべて使えます。

#### 読み取れる表記

まず**文字列全体**を次の表記として読みます。

`2026-08-15` / `2026/08/15` / `2026.08.15` / `20260815` / `2026年8月15日`
（月日は 1 桁でも構いません）

全体が日付でない場合は、**文中から最初の日付らしい並び**を取り出します。

| クリップボードの内容 | 読み取れる日付 |
| --- | --- |
| `リリース日: 2026/08/15 まで` | 2026/08/15 |
| `2026-08-15 14:30` | 2026/08/15（時刻は無視します） |
| `03-0000-0000` `090-1234-5678` | （なし。年が 4 桁でないため拾いません） |
| `2026-13-45` | （なし。存在しない日付のため） |
| `8/15` `15/08/2026` | （なし。年が先頭の 4 桁である必要があります） |

読み取れなかった場合、**トレイからのコピーは中止され**、「日付として読み取れません」と通知が出ます。
展開されなかった差し込みがそのまま貼り付けられてしまうのを防ぐためで、
クリップボードが空のときと同じ扱いです。設定画面のプレビューでは `{date@clip}` と書いたままが表示されます。

> `20260815` のような 8 桁の数字は日付として読みます。
> 8 桁の伝票番号などをコピーしている場合も日付になってしまいますが、
> これは区別のしようがないため、そのまま受け入れています。

> 地域設定によって `08/15/2026` を拾ったり拾わなかったりしないよう、
> 受け付ける表記は上に挙げたものだけに限っています。

> 正規表現に単独の `}` を書くことはできません（差し込みの終わりと区別できないため）。
> `\d{2,4}` のように `{` と `}` が対になっている書き方は問題ありません。

`{clip}` を含む項目を選んだときにクリップボードが空だと、コピーは行わず通知でお知らせします。
数値であれば `{calc:{clip}*1.1|#,##0}` のように計算式の中でも使えます。

## 計算式

`{calc:式}`（短く `{=式}`）でコピーする瞬間に計算します。`|` のうしろに .NET の数値書式を書けます。

```
小計 {calc:1200*3|#,##0} 円 / 消費税 {calc:1200*3*10%|#,##0} 円 / 合計 {calc:1200*3*1.1|#,##0} 円
→ 小計 3,600 円 / 消費税 360 円 / 合計 3,960 円
```

### 書ける記法

| 種類 | 内容 |
| --- | --- |
| 数値 | `1` `1.5` `1_000_000`（`_` は桁区切り。カンマは引数の区切りなので使えません） |
| 演算子 | `+` `-` `*` `/` `^`（べき乗）、単項の `-`、`×` `÷` も可 |
| べき乗の優先順位 | 単項の `-` が `^` より強いため `-2^2` は `4`（Excel と同じ）。`-(2^2)` はかっこで書く |
| 後置 `%` | `8%` は `0.08`。`1200*10%` で消費税額 |
| かっこ | `(` `)`（何重でも） |
| 定数 | `pi` `e` |
| 丸め | `round(x[,桁])`（四捨五入）`floor` `ceil` `trunc` |
| 数学 | `abs` `sign` `sqrt` `pow(x,y)` `mod(a,b)` `log(x[,底])` `log10` `exp` |
| 集計 | `min(...)` `max(...)` `sum(...)` `avg(...)`（引数はいくつでも） |

- 計算は `decimal` で行うので、`0.1+0.2` は `0.3` になります（金額の計算で誤差が出ません）
- かっこや符号の入れ子は 64 段までです（それ以上は式が誤っているものとして扱います）
- 書式を省略した場合は小数 10 桁までで、末尾の 0 は付きません（`2` / `1.5` / `0.3333333333`）
- 式が誤っていれば `{calc:…}` と書いたままが残るので、プレビューで気付けます

### 式の中で差し込みを使う

式の中には他の差し込みを書けます。連番や日付の数値と組み合わせると便利です。

```
請求書番号 {calc:{seq}*10|0000}      → 連番 7 なら 0070
納期まであと {calc:{daysuntil:2026-12-31}/7|0} 週
今月は {calc:{daysinmonth}-{day}} 日残っています
```

式の中で使えるのは**数値になる差し込み**だけです。`{date}`（`2026/07/30`）や `{guid}` のような
文字列の差し込みを書いた場合は計算せず、`{calc:…}` と書いたままの文字列が残ります。
`{year}` `{month}` `{day}` `{seq}` `{daysuntil:…}` などの数値の差し込み、または
`{date:yyyyMMdd}` のように数値だけになる書式を指定してください。

### スプリント

アジャイル開発のスプリントのように、一定の日数で区切って繰り返す期間を扱えます。
設定画面のフッターにある「スプリントの設定」で、**どれか 1 つのスプリントの開始日**（基準日）と
**1 スプリントの長さ**を決めると、そこから前後に区切りが並んでいるものとして計算します。

差し込みに `@sprint` と書くと、今日ではなく**今日を含むスプリントの開始日**が基準になります。

```
{date@sprint:yyyyMMdd}     → 20260727（今日が 8/1、7/27 開始のスプリント中なら）
{date@sprint+1sp}          → 次のスプリントの開始日   2026/08/10
{date@sprint+1sp-1}        → 今のスプリントの最終日   2026/08/09
{year@sprint} {month@sprint} {week@sprint}
```

スプリントの途中で月や四半期が変わっても値が動かないのが `{date}` との違いです。
たとえば 6/29〜7/12 のスプリント中に 7/2 にコピーしても、`{month@sprint}` は `6` のままです。

基準日を設定していない場合、`@sprint` や `sp` を使った差し込みは展開されず書いたまま残ります。

#### スプリント名の例

「年度 - 年度内の四半期」形式のスプリント名は、**3 か月ずらす**と条件分岐なしで書けます。
4 月を 1 月に寄せると、四半期が単なる割り算になり、1〜3 月を前年度に寄せる処理も同時に片付きます。

```
{calc:{year@sprint-3mo}-1996}-{calc:ceil({month@sprint-3mo}/3)}
```

| スプリント開始日 | 展開結果 |
| --- | --- |
| 2026/04/06 | `30-1` |
| 2026/06/29 | `30-1`（7/12 まで動かない） |
| 2026/07/27 | `30-2` |
| 2026/10/05 | `30-3` |
| 2027/01/04 | `30-4`（年度は繰り上がらない） |
| 2027/04/05 | `31-1` |

### 連番について

`{seq}` を含む項目には設定画面に「連番の設定」が表示され、**次の番号**と**増分**を指定できます。
コピーするたびに番号が進み、`settings.json` に保存されます。
増分に負の値を入れるとカウントダウンになります。

`{{seq}}` のようにエスケープした場合はリテラルの文字列 `{seq}` になるため、番号は進みません。

> 設定画面を開いている間にトレイからコピーして番号が進んだ場合、画面の「次の番号」も**その場で追従します**。
> 保存時にも `Id` で突き合わせて進んだ番号を引き継ぎます。
> 画面で「次の番号」を直接編集したときは、そちらの値が優先され、以降トレイ側の進みでは上書きされません。
> 追従は編集ではないため、これだけで「未保存」の状態にはなりません。

## 設定ファイル

`%APPDATA%\MyTaskTray\settings.json`

設定画面の左下「設定フォルダーを開く」で場所を開けます。手で編集することもできます。

```json
{
  "Version": 1,
  "ShowCopyNotification": true,
  "SprintAnchorDate": "2026-04-06T00:00:00",
  "SprintLengthDays": 14,
  "Items": [
    {
      "Id": "a1b2c3d4e5f60718293a4b5c6d7e8f90",
      "Name": "メールアドレス",
      "Text": "example@example.com",
      "Category": "",
      "IsSeparator": false,
      "SequenceValue": 1,
      "SequenceStep": 1
    },
    { "Name": "", "Text": "", "Category": "", "IsSeparator": true },
    { "Name": "今日", "Text": "{date:yyyy/MM/dd}", "Category": "日付", "IsSeparator": false }
  ]
}
```

| フィールド | 意味 |
| --- | --- |
| `ShowCopyNotification` | コピー時に画面右下へ通知を出すか（既定は `true`） |
| `SprintAnchorDate` | スプリントの基準日。`null` なら `@sprint` を使った差し込みは展開されない |
| `SprintLengthDays` | スプリント 1 つの日数（既定は `14`） |
| `Id` | 項目の識別子（自動生成。連番の引き継ぎに使用） |
| `Name` | メニューに表示する名前（空ならコピー文字列を表示） |
| `Text` | クリップボードにコピーする文字列（改行・差し込み可） |
| `Category` | サブメニュー名。空ならトップレベル |
| `IsSeparator` | `true` で区切り線として表示 |
| `SequenceValue` | `{seq}` が次に出力する番号 |
| `SequenceStep` | 連番の増分 |

ファイルが壊れていた場合は `settings.json.bak` に退避され、既定値で起動します。
一時的に読めなかっただけの場合（他のソフトがロックしているなど）は少し待って読み直します。
それでも読めなければ、既存の設定を失わないよう退避も上書きもせず、
メニューに「(設定を読み込めませんでした)」と表示します。この状態では連番の自動保存を行わず、
設定画面も開きません（開いて保存すると空の内容で上書きしてしまうため）。
メニューから「設定...」を選ぶと読み直しを試みるので、しばらく待ってからもう一度お試しください。

`Id` を書かずに項目を足した場合は、次回の読み込み時に自動で採番して書き戻します。

## 仕様メモ

- 二重起動は Mutex で防止します。
- トレイアイコンは `Resources/app.ico` を使用します。
- クリップボードが他プロセスにロックされている場合、最大 5 回まで再試行します。
- 配色は `AppsUseLightTheme` と DWM の `AccentColor` をレジストリから読み、Windows の設定変更に追従します。
  アクセント色が背景に対して読みにくい場合は明るさを補正します。
- コピー通知はフォーカスを奪わずに表示し、約 1.8 秒で消えます（クリックでも消えます）。

## 構成

```
App.xaml(.cs)               起動処理（ウィンドウなし常駐）
TrayIconManager.cs          トレイアイコンとメニューの生成
SettingsWindow.xaml(.cs)    設定画面
ToastWindow.xaml(.cs)       コピー完了の通知
DropIndicator.cs            並べ替え時の挿入位置を示す添付プロパティ
Converters.cs               バインディング用のコンバーター
Themes/Light.xaml           ライトテーマの色
Themes/Dark.xaml            ダークテーマの色
Themes/Controls.xaml        コントロールの見た目
Models/ClipItem.cs          コピー項目
Models/AppSettings.cs       設定全体
Services/SettingsStore.cs   JSON の読み書き
Services/ClipboardService.cs クリップボード操作
Services/ExpressionEvaluator.cs  {calc:…} の数式エンジン
Services/TemplateEngine.cs  差し込み（{date} など）の展開
Services/ThemeManager.cs    Windows の外観設定への追従
Services/TrayMenuTheme.cs   トレイメニューのダークテーマ描画
ViewModels/SettingsViewModel.cs 設定画面のビューモデル
ViewModels/PlaceholderRow.cs    差し込み一覧の 1 行
Resources/app-icon.svg      アイコンのマスター（256px 用）
Resources/app.ico           アプリ / トレイアイコン（16〜256px の 8 サイズ）
tools/make-icon.py          app-icon.svg から app.ico を生成する
```

### アイコン

墨色のタイルに白のカギ括弧「」を置いています。「あらかじめ用意された言葉」を道具ではなく言葉そのもので表す意図なので、
**中央の余白には何も足さない**でください。

16 / 20 / 24 / 32px は SVG の縮小ではなく `tools/make-icon.py` の中でピクセル単位に描き分けています
（縮小すると 2px の線が半端な位置に乗ってにじむため）。デザインを変えたら次を実行して `Resources/app.ico` を作り直します。

```
pip install cairosvg pillow
python tools/make-icon.py Resources/app-icon.svg Resources/app.ico
```
