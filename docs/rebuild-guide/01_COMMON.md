# 共通契約（毎回読む）

目的: 現行MyTaskTrayと同じ見た目・仕様を再現する。仕様追加・省略・別UIへの置換はしない。
対象: Windows、C#、net10.0-windows、WPF + WinForms NotifyIcon/ContextMenuStrip。製品の外部依存はMarkdig 1.2.0のみ。既存バージョンに固定した再現仕様。

1. 今回の段階だけ実装する。後続機能の仮入口はビルド可能な状態で無効化し、PROGRESSへ記録。最終段階で全て接続する。
2. 保存形式はVersion3。項目Id/CategoryId、通常・条件付きの独立順序を維持。
3. UIの文言・寸法・色は04_UIとspecs/ui-*。タブ式への改善案は実装しない。
4. WPF/WinFormsの同名型を明示的に区別。ClipboardはSTA、UI更新はDispatcher。
5. テストに利用者の実settings.jsonや実クリップボード内容を使わない。一時設定・架空データで確認する。
6. 成功コピーで連番を1回進める。プレビュー・試しコピー・取消・失敗では進めない。自動展開は入力注入まで成功後に進める。
7. 入力収集/連続コピー/選択中/Swap/自動展開の競合を防ぐ。進行中のデータを別機能が暗黙に破棄しない。
8. 判定不能時: クリップ条件は非一致、アプリ表示条件は表示、自動展開は何もしない。機能ごとの差を保持。
9. 本資料だけで実装する。元リポジトリや旧設計書を別環境で探す必要はない。
10. 今回必要なビルド・確認を実施し、未実施は明示。確認例が記載されているだけで合格扱いにしない。
11. 毎回PROGRESSを目安40行以内で更新。回答は変更・検証・未確認のみ、コード全量再掲を避ける。
12. 詳細仕様と補足が違う場合は段階別の「現行補足」を優先。推測の新仕様で埋めず差異を進捗に記録。
