# MyTaskTray 再構築 guide版

## 目的

現在のMyTaskTrayを、別のWindows環境で空のプロジェクトから段階的に実装するための日本語設計書・指示書です。元ソース・XAML・画像・テストコード等の参考ファイルは同梱しません。実装に必要な情報を文書へ整理しています。

基準: 2026-09-15に確認したコミット `919325b9a645d7ad6eb665dfcce11c122db4d28d`。作成日2026-09-16。
既存の `DESIGN_SETTINGS_UI.md` は未実装の改善提案なので再現対象外です。タブ式設定画面、Undo/Redo、多階層カテゴリ、if構文、Table形式などを追加しないでください。

## 開始方法

1. このフォルダーを別環境の新規作業フォルダーへ `rebuild-guide/` の名前で置く。
2. AIへ `prompts/01.md` の指示文を渡す。
3. その段階のビルド・確認後、次の番号の指示へ進む。
4. 新しい会話へ移るときは `prompts/RESUME.md` を使う。実装状態は `PROGRESS.md` に残す。
5. 最後は段階19と `05_ACCEPTANCE.md` で総合確認する。

ファイルを読めないAIでは、共通契約、当該段階、その段階の必読仕様だけを貼り付けてください。

## トークンの節約

**全資料を一度に読ませない**でください。最初に01_COMMON、PROGRESS、今回のstagesファイルだけ読み、指定された必読仕様を追加します。画面仕様は対象セクションのみ読みます。
大きい段階は記載した小分けの1項目ずつ実装しても構いません。1段階が必ず特定のトークン数以内に収まる保証ではありません。
コードはファイルへ直接編集させ、回答への全量再掲を避けます。進捗は目安40行以内で書き換え、実況を蓄積しません。

## 構成

| 資料 | 用途 |
| --- | --- |
| 01_COMMON.md | 毎回読む短い共通契約 |
| 02_ARCHITECTURE.md | 技術構成と機能間の接続 |
| 03_DATA.md | モデル、保存、初期値、互換性 |
| 04_UI.md | 外観の全体設計 |
| stages/01.md～19.md | 段階別の実装指示・完了条件 |
| prompts/ | 貼り付け用指示と再開用指示 |
| specs/ | 各機能の詳細文法・画面数値仕様 |
| 05_ACCEPTANCE.md | 最終確認表 |
| PROGRESS.md | 新環境で更新する引き継ぎ書 |

## 最初に貼る指示

```text
rebuild-guide/01_COMMON.md、PROGRESS.md、stages/01.mdを読み、
段階01だけを実装してください。追加で読むのは段階01の必読資料だけにしてください。
ビルドと指定の確認を行い、PROGRESS.mdを更新してください。
次段階には進まず、変更・確認結果・次回の開始点だけ簡潔に報告してください。
```

## 再現精度

コードから現行の寸法・配色・文言・動作を確認しました。今回、元アプリの画面を操作して外観比較した資料ではありません。
Windows版、DPI、フォント、地域、アクセント色を合わせ、最終段階で表示を照合してください。
アイコンはspecs/icon.mdのサイズ別作図仕様から作れます。元バイナリは同梱しないため、描画ライブラリによるアンチエイリアスまで完全一致する保証はありません。
