# 段階17: Swapコピー

前提: 段階16まで完了。01_COMMONとPROGRESSを読む。

## 必読資料

- [specs/swap.md](../specs/swap.md)

## 実装・完了条件

ホットキー専用、トレイ項目を作らない。作業セッション中拒否し通知。実行中の再入防止。
1. ClipboardSnapshot Aを退避。GetFormats(false)で全形式、Stream等可変値は独立化。拒否印も保持。空/不可なら何もしない。
2. 修飾キー解放、Ctrl+C送信。20ms間隔で最大800ms更新番号変化待ち。変化なしは選択なし。変化後60ms待ちBを退避。
3. Aを復元できた時だけCtrl+V。復元失敗は貼らない。送信失敗はA維持。
4. 350ms待ち、第三者コピーで番号が変化していたら上書きせず終了。他はB復元。
STA上のasync、Thread.SleepでUIを止めない。
結果はSuccess/ClipboardEmpty/ClipboardUnavailable/NothingSelected/InputBlocked/OriginalRestoreFailed/SelectionRestoreFailed/SelectionOverwritten。
成功だけ通知設定に従う。その他は必ず「できません/中断/貼り付けまで完了」を区別して通知。選択なし=コピーが行われなかった、A復元失敗=Bが残り未貼付、B復元失敗=貼付済み、第三者コピー=その新コピーを優先した、と明示する。
確認: 選択B/ClipboardA→選択A/ClipboardB、HTML/画像を平文化しない、空/選択なし/読み書き送信失敗/待機中第三者コピー/作業中拒否。

## 終了時

ビルドと指定の確認。PROGRESSを更新し未接続/未確認を残す。次段階へ進まない。上限が近ければ小分けで止め、次の開始点を記録する。
