## 実装・完了条件

「複数行にまとめて適用する」節を読む。
ApplyToEachLine && 非区切り && ClipboardCondition!=Alwaysのみ有効。Alwaysに戻して保存フラグが残っても処理は無効。
RegexはCRLF/CR→LFへ揃え、Multilineで全文を非重複反復照合。match:valueは各一致。その他は行ごと、TrimEndのみで先頭の空タブ列を保持。
上限200件、合計200ms/項目。0件なら非表示。打切り状態をtooltip/設定へ通知。結果CRLF連結、全件同じnow/seq、成功でseq1回。
clipは各行ではなく元の全文。tooltipは件数+先頭1件、通知は件数。
JSONの複数行チェックは現行で選択可だが、整形JSONは行単位では通常一致しない。JSON配列を要素展開する別仕様を追加しない。
確認: 先頭空タブ列、2行またぎRegex、200超、病的パターン、全件非一致、時刻/連番が件数分変わらない。
