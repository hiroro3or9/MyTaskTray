# 動的表示と省略の契約

画面のBindingが返す文字列を揃えるための補足。対象の段階で必要な節だけ読む。

## 共通の1行表示

CRを除去、LFを「⏎ 」へ、Tabを半角空白4つへ置換してから短縮。
短縮はUTF-16長が上限を超えたとき先頭maxLength文字+「…」。切断直前が上位サロゲートなら1文字手前で切り、絵文字を分断しない。

## 設定の項目行

DisplayLabel: Nameが空白でなければName。空ならTextが空白だけの場合「(名前なし)」、それ以外はTextを1行化して40文字。
TextPreview: Textが空なら「(空)」、それ以外は1行化して60文字。
トレイの空項目ラベルは別で「(空の項目)」。設定画面の未命名表示と混同しない。
カテゴリ名空で改名を確定: 「カテゴリ名を入力してください。トップレベルへ移す場合は『カテゴリを削除』を使います。」（実表示の括弧は「」）。
既存名へ改名: 「『名前』はすでにあります。2つのカテゴリをまとめますか？」をOKCancel（実表示の括弧は「」）。

## 連続コピー進捗

| 状態 | 表示 |
| --- | --- |
| 収集Title | 連続コピー |
| 貼付Title | 連続貼り付け |
| 収集Status | N 件を収集済み |
| 貼付Status | 次は P+1 / N 件目 |
| 次がない時 | 貼り付けを完了しています… |
| 収集preview見出し | 最後にコピーした内容 |
| 貼付preview見出し | 次に貼り付ける内容 |
| 未収集preview | コピーすると、ここに内容が表示されます |
| 送信終了preview | すべての内容を送りました |
| 収集Hint | 貼り付け先で Ctrl+V を押すと、1 件目から貼り付けます。 |
| 貼付Hint | Ctrl+V で次へ · 残り N-P 件 |

Nは総数、Pは送信済み数。メインpreviewは1行化180文字、一覧previewは160文字。
一覧の送信済み番号は✓、他は現在の表示順+1。次の行だけIsNext=true。
CanRemoveは収集中、上下は収集中かつ範囲内。上部Undo/貼付へは収集中かつN>0。
表示更新時にClipboardを読み直さず、Queueの値だけから作る。

## 収集したデータ

連続コピーのIDはセッション内で1から増やし、並べ替えても変更しない。削除で再採番しない。
Captureは収集中だけ、TryMoveはoffset=-1または+1かつ範囲内だけ。QueueのAdvanceはClipboard書込成功後のみ。
