# 選択肢から選ぶ

コピー文字列に `{choice:名前:選択肢|選択肢}` を書くと、項目を選んだあとにメニューが出て、
どれでコピーするかをその場で選べます。

```text
{choice:挨拶:お世話になっております|お疲れ様です}。{choice:部署:営業部|開発部}の田中です。
```

この項目を選ぶと「挨拶（1/2）」のメニューが出て、選ぶと続けて「部署（2/2）」が出ます。
両方選ぶと、たとえば次のような文字列をコピーします。

```text
お疲れ様です。開発部の田中です。
```

社内と社外で書き分ける、担当や状態を選ぶ――といった「毎回どちらかを選ぶ」文章のためのものです。
同じ内容を項目に分けると、選択肢が 2 か所あるだけで 4 項目必要になり、
共通部分を直すたびに全部を直すことになります。`{choice}` はこれを 1 項目にまとめます。

### 書き方

- **名前を先に書きます。** `{choice:敬称:様|御中}` の「敬称」が名前、`様` と `御中` が選択肢
- 2 回目以降は **`{choice:敬称}` と名前だけ**書けば、選んだものが同じように差し込まれます

  ```text
  {choice:担当:田中|佐藤}さんへ引き継ぎました。
  以降のご連絡は{choice:担当}さんまでお願いいたします。
  ```

- 選択肢は `|` で区切って **2〜20 個**。範囲外だと差し込みは展開されず、書いたまま残ります
- 選択肢に `|` そのものを入れたいときは `\|` と書きます
- 波かっこは `{{` `}}` と書きます
- **空の選択肢も書けます。** `{choice:急ぎ:|【至急】}` は「付けない / 【至急】」の 2 択で、
  メニューには `(空)` と出ます
- 前後の空白は取り除きません（`, ` のような区切り文字そのものを選ばせるため）
- 名前に `|` と `:` は使えません。選択肢には `:` を使えます（`{choice:開始:10:00|15:30}`）

### 選ぶときの操作

- 選択肢のメニューは**ホットキーで出るメニューと同じもの**です。数字キー・矢印キー・Enter で選べます

  ```text
  ホットキー → 3（項目）→ 2（挨拶）→ 1（部署）→ コピー完了
  ```

- 各選択肢にマウスを乗せると、**それを選んだ場合の完成形**がツールチップに出ます
- 2 つめ以降のメニューには「← 戻る」があり、前の選択をやり直せます
- Esc または別の場所をクリックすると中止し、何もコピーしません
- 選び終えると、メニューを開く前に使っていたウィンドウへフォーカスが戻ります

### 設定画面での見え方

- プレビューには**先頭の選択肢**を選んだ場合の文字列が出ます。
  そのことはプレビューの上に書かれます（実際に選ぶのはコピーするときです）
- 選択肢の内訳（`2 か所で選びます: 挨拶（2 択） → 部署（2 択）`）も同じ場所に出ます
- 書き方を誤っている場合は、貼り付ける前に気付けるようその場で理由が出ます
- 「コピーして試す」は、プレビューどおり**先頭の選択肢で**コピーします

### いくつでも選ぶ

`{choice}` を `{choices}`（複数形）にすると、いくつでも選べるようになります。
選んだものは `、` でつないで差し込みます。

```text
{date:M/d} 定例議事録
出席者: {choices:出席者:田中|佐藤|鈴木|高橋}
```

この項目を選ぶとチェック付きのメニューが出ます。
「田中」と「鈴木」を選んで「決定」を押すと、次のようになります。

```text
8/8 定例議事録
出席者: 田中、鈴木
```

- **クリックしてもメニューは閉じません。** チェックが付いたり外れたりします。
  番号キーでも同じように反転します
- 選び終えたら**「決定」**を押します。ここで初めて閉じます
- Esc または別の場所をクリックすると中止し、何もコピーしません
- **つなぐ順番は、選択肢を書いた順です**（クリックした順ではありません）。
  上の例で「鈴木 → 田中」の順に押しても `田中、鈴木` になります
- **1 つも選ばずに「決定」を押せます。** その場合は空文字になります。
  「決定」にマウスを乗せると、いま何件選んでいるかと結果が出ます
- 選択肢の書き方・個数の上限・名前による参照（`{choices:出席者}`）は `{choice}` と同じです
- ただし**空の選択肢には意味がありません。** チェックを付けても結果は変わりません
  （何も選ばなければ同じ結果になるため。単一選択の `{choice}` では「付けない」という意味を持ちます）

つなぐ文字は `、` で固定です。ほかの文字を指定する書き方はまだありません。

### 選択肢の中に差し込みを書く

選択肢そのものを差し込みで作れます。

```text
{choice:期限:{date}|{date+1}|{date+1w}}までにご対応ください
```

メニューには展開後の日付が並びます。

```text
1　2026/08/08
2　2026/08/09
3　2026/08/15
```

**展開はメニューを出すときに 1 回だけ**行います。`{guid}` や `{time}` のように評価するたびに変わるものでも、
**メニューで見た値がそのままコピーされます**。

使えない差し込みが 4 つあります。混ざっていると定義として扱われず、書いたまま残ります（設定画面に理由が出ます）。

| 使えない | 理由 |
| --- | --- |
| `{input:名前}` | 入力を集めるのは選択の**あと**なので、メニューに出す時点で値がありません |
| `{choice:…}` `{choices:…}` | 選択肢の中の選択を先に決めないとメニューを出せず、堂々巡りになります |
| `{seq}` | 値は出せますが、**その選択肢を選ばなくても連番が進みます**。番号が飛ぶので許していません |

`{date}` `{clip}` `{calc:…}` `{match:名前}` `{guid}` `{random}` などは使えます。
波かっこそのものを選択肢にしたい場合は `{{` `}}` と書きます。

### いまできないこと

- HTML 形式の項目では、選択肢に含まれる `<` や `&` はエスケープされます（`{input:名前}` と同じ）。
  タグを選ばせることはできません
- `{choices}` でつなぐ文字を `、` 以外にはできません
