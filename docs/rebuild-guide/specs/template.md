# 差し込み（日付などの計算値）

コピー文字列には `{...}` 形式の差し込みを書けます。コピーした瞬間に評価されるので、固定文と混ぜて使えます。

```
{date:yyyy/MM/dd} 定例ミーティング 議事録
→ 2026/07/30 定例ミーティング 議事録
```

設定画面の「差し込みを挿入 ▾」を押すと、前面アプリ / クリップボード / 日付 / 時刻 / スプリント / 月・週 / 計算 / 日付の数値 / 連番・その他のグループに分かれた一覧が開きます。
各行には**いま挿入した場合の値**が並ぶので、書式を確かめてから選べます。上の欄でキーワード検索もできます。
選ぶとカーソル位置に挿入され、下部のプレビューで実際にコピーされる文字列を確認できます。

プレビューは `{time}` などを含むときだけ 1 秒ごとに更新します。
`{clip}` の値は、他のアプリでコピーしてから設定画面に戻ってきたタイミングで読み直します
（入力のたびにクリップボードを開くと、他アプリのコピー操作を妨げるため）。

### 書式

```
{名前[@基準][±数値[単位]]…[:書式]}
{calc:式[|数値の書式]}
```

- 書式は .NET の書式指定文字列。日付なら `yyyy/MM/dd`、`yyyy年M月d日`、`ddd`（曜日）など
- **基準**は、日付を今日以外から数え始めたいときに書きます

  | 基準 | 起点 |
  | --- | --- |
  | `@sprint` | 今日を含むスプリントの開始日（→ スプリント） |
  | `@clip` | クリップボードに入っている日付（→ クリップボードの日付） |
  | `@date` `@monthstart` `@monthend` `@weekstart` `@weekend` | 同じ名前の差し込みと同じ日 |

  基準そのものにオフセットは書けません。`{year@sprint-3mo}` の `-3mo` は**結果のほう**に掛かります
- 単位は `d` 日 / `w` 週 / `mo` 月 / `y` 年 / `h` 時 / `mi` 分 / `s` 秒 / `sp` スプリント。
  省略時は差し込みの名前に合わせた単位になります

  | 省略時の単位 | 差し込み |
  | --- | --- |
  | 日 | `{date}` `{datetime}` `{day}` `{dow}` `{doy}` |
  | 週 | `{weekstart}` `{weekend}` `{week}` |
  | 月 | `{monthstart}` `{monthend}` `{month}` `{daysinmonth}` |
  | 年 | `{year}` |
  | 時 | `{hour}` |
  | 分 | `{time}` `{minute}` |
  | 秒 | `{second}` |

- **オフセットは重ねて書けます**。書いた順に適用されます

  ```
  {date+1mo-1}          翌月の前日
  {date@sprint+1sp-1}   今のスプリントの最終日
  {date@sprint+2sp-1}   次のスプリントの最終日
  ```

  ただし `{monthstart}` `{monthend}` `{weekstart}` `{weekend}` は
  **オフセットを適用したあとに**月初・月末・週初・週末を求めます。
  `{monthstart+1mo-1}` は「翌月の前日を含む月の初日」＝今月の初日であって、月末ではありません
  （月末は `{monthend}`）
- 数値は、書式を指定しなければ地域設定に左右されない表記、
  書式を指定した場合は桁区切りなどが地域設定に従います（`{seq}` `{month}` `{calc:…}` で共通）
- `{{` と `}}` はそれぞれ `{` `}` そのものを表す
- 解釈できない差し込みは、書いたままの文字列が残るので誤りに気付けます。
  未知の名前だけでなく、**単位の書き間違い**（月は `m` ではなく `mo`、分は `min` ではなく `mi`）や、
  オフセットを付けられない差し込み（`{guid+1}` `{random+5}` `{daysuntil+1:…}` など）も
  同様に展開されずそのまま残ります

### 一覧

| 差し込み | 内容 | 例 |
| --- | --- | --- |
| `{app:name}` | メニューを開く直前に前面だったアプリ名（`.exe` は除く） | `code` |
| `{app:title}` | メニューを開く直前に前面だったウィンドウのタイトル | `README.md - MyTaskTray - Visual Studio Code` |
| `{app:title:/正規表現/}` | タイトルから最初の一致を取り出す。キャプチャがあればその値 | `{app:title:/Issue #(\d+)/}` → `4329` |
| `{app:name:/正規表現/}` | アプリ名から最初の一致を取り出す。キャプチャがあればその値 | |
| `{clip}` | いまコピーしてある文字列（前後の空白は除く） | `4329` |
| `{clip:digits}` | 最初の数字だけを取り出す | `4329` |
| `{clip:/ID-(\d+)/}` | 正規表現で取り出す（かっこがあればその中身） | `4329` |
| `{clip:line}` | 1 行目だけ | |
| `{clip:upper}` / `{clip:lower}` | 大文字 / 小文字にする | |
| `{clip:raw}` | 空白・改行も含めてそのまま | |
| `{input:名前}` | 項目を選んだあと、名前ごとにコピーした値を順番に取得 | |
| `{input:名前:/ID-(\d+)/}` | 正規表現に一致する入力だけを受け取り、最初のキャプチャ（なければ一致全体）を取得 | `4329` |
| `{match:名前}` | スマートアクションの表示条件で取り出した値 | |
| `{replace:{clip}\|検索\|置換}` | 差し込み結果に含まれる文字列をすべて置換 | |
| `{regexreplace:{clip}\|パターン\|置換}` | 正規表現に一致する箇所をすべて置換 | |
| `{date}` | 今日の日付 | `2026/07/30` |
| `{date:yyyyMMdd}` | 書式を指定した日付 | `20260730` |
| `{date+1}` / `{date-1}` | 明日 / 昨日 | `2026/07/31` |
| `{date+1w}` `{date+2mo}` `{date-1y}` | 週・月・年の加減算 | `2026/08/06` |
| `{time}` | 現在の時刻 | `14:05` |
| `{time:HH:mm:ss}` | 秒まで含む時刻 | `14:05:32` |
| `{time+30}` | 30 分後 | `14:35` |
| `{datetime}` | 日付と時刻 | `2026/07/30 14:05` |
| `{monthstart}` / `{monthend}` | 今月の初日 / 末日 | `2026/07/01` / `2026/07/31` |
| `{monthend+1}` | 翌月の末日 | `2026/08/31` |
| `{weekstart}` / `{weekend}` | 今週の月曜 / 日曜 | `2026/07/27` / `2026/08/02` |
| `{date@sprint}` | 今日を含むスプリントの開始日 | `2026/07/27` |
| `{date@sprint+1sp}` | 次のスプリントの開始日（`-1sp` で前） | `2026/08/10` |
| `{date@sprint+1sp-1}` | 今のスプリントの最終日 | `2026/08/09` |
| `{date@clip:yyyyMMdd}` | クリップボードの日付を別書式に | `20260815` |
| `{date@clip+1w}` | クリップボードの日付の 1 週間後 | `2026/08/22` |
| `{week@clip}` `{dow@clip}` | その日の ISO 週番号 / 曜日番号 | `33` / `6` |
| `{seq}` | 連番（コピーごとに増える） | `7` |
| `{seq:0000}` | 桁を揃えた連番 | `0007` |
| `{seq+1}` | 次の番号 + 1（範囲を書くときなど） | `8` |
| `{guid}` | GUID（小文字・ハイフンあり） | `3f2a…` |
| `{guid:N}` `{guid:B}` `{guid:U}` | ハイフンなし / 波かっこ付き / 大文字 | |
| `{random}` / `{random:1-6}` | 乱数（既定は 1〜100。`{random:-5-5}` のように負の範囲も可） | `42` |
| `{year}` `{month}` `{day}` | 年 / 月 / 日を数値で | `2026` `7` `30` |
| `{month:00}` | 桁を揃えた月 | `07` |
| `{hour}` `{minute}` `{second}` | 時 / 分 / 秒を数値で | `14` `5` `32` |
| `{dow}` | 曜日番号（月曜=1 〜 日曜=7） | `4` |
| `{week}` / `{doy}` | ISO 週番号 / 元日からの通日 | `31` / `211` |
| `{daysinmonth}` | 今月の日数 | `31` |
| `{daysuntil:2026-12-31}` | 指定日までの日数（過去なら負） | `154` |
| `{calc:式}` / `{=式}` | 計算式（下記） | `{calc:1+2}` → `3` |

日付の数値は `{year+1}` のようにオフセットも書けます（単位の既定は名前に合わせて年・月・日…）。
