# 使い方

1. ビルドして実行すると、ウィンドウは開かずタスクトレイにアイコンが表示されます。
2. トレイアイコンを **左クリック または 右クリック** するとコピー項目の一覧が出ます。クリックすると、その項目の文字列がクリップボードにコピーされます。
   設定画面でホットキーを指定すると、カーソル位置に同じメニューを表示できます。表示後は ↑ / ↓ と Enter で選択できます。項目には `1`〜`9`・`0` の番号が振られるので、**ホットキー → 数字の 2 打鍵**でコピーできます。カテゴリ（サブメニュー）は開いたときに 1 から番号が振り直されるため、`ホットキー → 3 → 2` のように 3 打鍵で中の項目まで届きます。ホットキーから開いた場合だけ「終了」は表示されません。既定では無効です。
   指定できるキーは ホットキーに指定できるキー を参照してください。
   無変換や `F13` のように**文字を入力しないキーは、修飾キーなしの単体でも指定できます**。
3. コピーすると画面右下に小さな通知が出ます（設定画面でオフにできます）。
4. メニュー →「クリップボードを項目に追加...」で、いまコピーしてある文字列をその場で項目にできます（→ クリップボードをその場で項目にする）。
5. 設定画面はメニュー →「設定...」から開きます。
6. 終了はメニュー →「終了」。

見た目は Windows の外観設定（ライト / ダーク、アクセント色）に自動で合わせます。設定を変更すると、起動したまま切り替わります。
