# 設定画面

左がトレイメニューの構成、右が選択した項目またはカテゴリの編集欄です。
左側は「通常メニュー」と、条件に合う項目が入る「この内容でできること」に分かれ、
カテゴリは折りたためる見出しとして表示されます。項目は 1 行目に表示名、2 行目にコピーされる文字列、
右端に形式・カテゴリ・連番などのバッジが出ます。

| 操作 | 説明 |
| --- | --- |
| 検索 | 表示名・コピー文字列・カテゴリで絞り込みます（絞り込み中は並べ替えできません） |
| 追加 | 新しいコピー項目を選択位置の下に追加します |
| 区切り線 | メニューに水平線を入れます（グループの区切り用） |
| 複製 | 選択項目をコピーします |
| 削除 | 選択項目を削除します（中身のある項目は確認します） |
| ▲ / ▼ | 選択した項目、またはカテゴリ全体を現在の階層内で並べ替えます |
| 行のドラッグ | 項目の並べ替え、カテゴリ間の移動、トップレベルへの移動ができます。カテゴリ見出しを動かすと配下をまとめて移動します |
| コピーして試す | プレビューの内容をそのままコピーします（連番は進みません） |
| アクションの表示 | 組み込みアクションを「作業ツール」「この内容でできること」に分けて示し、個別に表示を切り替えます |

保存せずに閉じようとすると、保存するかどうかを確認します。

### ショートカット

| キー | 動作 |
| --- | --- |
| Ctrl+F | 検索欄へ移動 |
| Ctrl+N | 項目を追加 |
| Ctrl+D | 選択項目を複製 |
| Alt+↑ / Alt+↓ | 選択項目を上下に移動（入力欄にカーソルがあるときは無効） |
| Delete | 一覧で選択中の項目を削除 |
| Ctrl+S | 保存して閉じる |
| Esc | キャンセル（ポップアップが開いているときは閉じる） |

### ホットキーに指定できるキー

メニュー表示と Swap コピーの両方で、書き方は同じです。
`Ctrl+Alt+V` のように `+` で区切り、`Ctrl` / `Alt` / `Win` のいずれかを含めます。

| 種類 | 指定できるもの |
| --- | --- |
| 通常のキー | `A`〜`Z`、`0`〜`9`、`F1`〜`F24` |
| 修飾キー | `Ctrl`、`Alt`、`Shift`、`Win`（`Ctrl` / `Alt` / `Win` のどれかは必須） |

**文字を入力しないキーだけは、修飾キーなしの単体でも指定できます。**
入力欄でそのキーを押すと入ります（名前を打っても構いません）。

| キー | 名前での書き方 | 登録しているあいだ使えなくなるもの |
| --- | --- | --- |
| 無変換 | `無変換` / `muhenkan` | IME のオフ操作 |
| 変換 | `変換` / `henkan` | **IME の変換・再変換**。日本語入力でよく使うので注意 |
| アプリケーションキー | `アプリケーション` / `apps` | 右クリックメニュー（`Shift+F10` で代替できます） |
| Pause | `Pause` / `break` | ほぼありません |
| `F13`〜`F24` | `F13` など | ありません（普通のキーボードには無いキーです） |

通常の文字キーを単体で登録できないのは、そのキーが全アプリで打てなくなり、
設定画面でも打てないため元に戻せなくなるからです。

#### CapsLock は指定できません

CapsLock・NumLock・ScrollLock は**押すたびに状態が反転し、その反転はホットキーの処理より下で起きます。**
登録しても大文字ロックが点いたり消えたりするため、対象から外しています。

CapsLock の位置で使いたい場合は、PowerToys の Keyboard Manager などで
**CapsLock を `F13` や無変換に割り当ててから**、このアプリでそのキーを指定してください。
押す指は CapsLock のまま、衝突のないホットキーになります。

### カテゴリ（サブメニュー）

「配置先」に名前を入れると、その名前のサブメニュー配下にまとまります。空欄ならトップレベルに表示されます。
設定画面ではカテゴリが見出しとして表示され、折りたたみ、ドラッグによる並べ替え、名前の一括変更ができます。
カテゴリを削除しても中の項目は削除されず、トップレベルへ移ります。
項目編集欄の「配置先」へ新しい名前を直接入力すると、新しいカテゴリを作れます。
右の「▾」から既存カテゴリまたはトップレベルを選ぶこともできます。

カテゴリ見出しを選ぶと、識別しやすいプリセット色とアイコンを設定できます。
装飾は設定画面の見出し・配置先候補・クイック追加候補と、実際のトレイメニューへ共通して表示されます。
色だけなら小さな色印、アイコンも選ぶとその色のアイコンとして表示されます。
「装飾をリセット」で色・アイコンをまとめて外せます。

カテゴリには表示名とは別の固定IDがあり、名前を変えても所属と並び順は保たれます。
通常メニューと「この内容でできること」はそれぞれ独立した配置順を持つため、
同じカテゴリを両方で使っても、各領域で好きな位置へ並べられます。
