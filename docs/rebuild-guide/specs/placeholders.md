# 差し込み挿入候補の設計

この順で登録し、グループ別に表示する。各行の現在値は同じ展開器で評価。検索対象はトークン・説明・グループ。

| トークン | グループ | 説明 |
| --- | --- | --- |
| {app:name} | 前面アプリ | メニューを開く直前に前面だったアプリ名（.exe は除く） |
| {app:title} | 前面アプリ | メニューを開く直前に前面だったウィンドウのタイトル |
| {app:title:/Issue #(\d+)/} | 前面アプリ | タイトルを正規表現で取り出す（かっこがあればその中身） |
| {app:name:/^(.*)$/} | 前面アプリ | アプリ名を正規表現で取り出す |
| {clip} | クリップボード | いまコピーしてある文字列（前後の空白は取り除く） |
| {clip:digits} | クリップボード | コピー済みの文字列から最初の数字だけを取り出す |
| {clip:/ID-(\d+)/} | クリップボード | 正規表現で取り出す（かっこがあればその中身） |
| {clip:line} | クリップボード | 1 行目だけを取り出す |
| {clip:upper} | クリップボード | 大文字にする（lower で小文字） |
| {clip:raw} | クリップボード | 空白や改行も含めてそのまま |
| {input:名前} | 複数入力 | 項目を選んだあと、名前ごとにコピーした値を順番に差し込む |
| {input:Issue URL:/issues/(\d+)/} | 複数入力 | 正規表現に一致する入力だけを受け取り、かっこの中身を差し込む |
| {match:名前} | スマートアクション | 正規表現などの表示条件で取り出した値を差し込む |
| {choice:敬称:様&#124;御中} | 選択肢 | コピーするときにメニューで選ぶ（2〜20 個まで） |
| {choice:敬称} | 選択肢 | 同じ名前を書けば、選んだものを 2 か所以上に差し込める |
| {choice:急ぎ:&#124;【至急】} | 選択肢 | 空の選択肢も書ける（付けない / 【至急】） |
| {choices:出席者:田中&#124;佐藤&#124;鈴木} | 選択肢 | いくつでも選べる。選んだものを「、」でつなぐ |
| {replace:{clip}&#124;検索&#124;置換} | 文字列変換 | 差し込み結果に含まれる文字列をすべて置き換える |
| {regexreplace:{clip}&#124;\s+&#124;-} | 文字列変換 | 正規表現に一致する箇所をすべて置き換える |
| {date@clip:yyyyMMdd} | クリップボードの日付 | コピーしてある日付を別の書式にする（2026/08/15 → 20260815） |
| {date@clip:yyyy年M月d日} | クリップボードの日付 | 和文の日付にする |
| {date@clip:ddd} | クリップボードの日付 | その日の曜日 |
| {date@clip+1w} | クリップボードの日付 | その 1 週間後（単位は {date} と同じ） |
| {week@clip} | クリップボードの日付 | その日の ISO 週番号（{month@clip} なども同様） |
| {date} | 日付 | 今日の日付 |
| {date:yyyyMMdd} | 日付 | 書式を指定した日付 |
| {date:yyyy年M月d日} | 日付 | 和文の日付 |
| {date+1} | 日付 | 明日（-1 で昨日） |
| {date+1w} | 日付 | 1週間後（単位 d 日 / w 週 / mo 月 / y 年） |
| {time} | 時刻 | 現在の時刻 |
| {time:HH:mm:ss} | 時刻 | 秒まで含む時刻 |
| {time+30} | 時刻 | 30分後（単位 h 時 / mi 分 / s 秒） |
| {datetime} | 時刻 | 日付と時刻 |
| {hour} | 時刻 | 現在の時（0〜23。{hour:00} で 2 桁） |
| {minute} | 時刻 | 現在の分（0〜59） |
| {second} | 時刻 | 現在の秒（0〜59） |
| {date@sprint} | スプリント | 今日を含むスプリントの開始日（設定の基準日と長さから求める） |
| {date@sprint:yyyyMMdd} | スプリント | 書式を指定したスプリント開始日 |
| {date@sprint+1sp} | スプリント | 次のスプリントの開始日（-1sp で前のスプリント） |
| {date@sprint+1sp-1} | スプリント | 今のスプリントの最終日（オフセットは重ねて書ける） |
| {calc:{year@sprint-3mo}-1996}-{calc:ceil({month@sprint-3mo}/3)} | スプリント | スプリント名。3 か月ずらして年度と年度内四半期（4〜6月=1）を求める |
| {year@sprint-3mo} | スプリント | スプリント開始日の年度（4 月始まり。1〜3 月は前年度） |
| {calc:ceil({month@sprint-3mo}/3)} | スプリント | スプリント開始日の年度内四半期（1〜4） |
| {monthstart} | 月・週 | 今月の初日（+1 で翌月） |
| {monthend} | 月・週 | 今月の末日（+1 で翌月） |
| {weekstart} | 月・週 | 今週の月曜日（+1 で翌週） |
| {weekend} | 月・週 | 今週の日曜日 |
| {date+1mo-1} | 月・週 | 翌月の前日（オフセットは重ねて書ける） |
| {week@monthstart} | 月・週 | 今月 1 日の ISO 週番号（@ で基準の日を差し替える） |
| {calc:(1000+200)*1.1} | 計算 | 式を計算する（+ - * / ^ とかっこ） |
| {calc:1000*8%} | 計算 | パーセント。8% は 0.08 として扱う |
| {calc:1000*1.1&#124;#,##0} | 計算 | | のうしろは数値の書式（#,##0 / 0.00 など） |
| {calc:round(1000/3,2)} | 計算 | 四捨五入。floor / ceil / trunc も同様 |
| {calc:max(1,2,3)} | 計算 | 関数: min max sum avg abs sqrt pow mod sign log exp |
| {calc:{seq}*100} | 計算 | 式の中で他の差し込みを参照できる |
| {=1+2} | 計算 | {calc:…} の短い書き方 |
| {year} | 日付の数値 | 今年（4 桁の数値。+1 で翌年） |
| {month} | 日付の数値 | 今月（1〜12。{month:00} で 2 桁） |
| {day} | 日付の数値 | 今日の日（1〜31） |
| {dow} | 日付の数値 | 曜日番号（月曜=1 〜 日曜=7） |
| {week} | 日付の数値 | ISO の週番号 |
| {doy} | 日付の数値 | 元日からの通日 |
| {daysinmonth} | 日付の数値 | 今月の日数 |
| {daysuntil:2026-12-31} | 日付の数値 | 指定日までの日数（過ぎていれば負の数） |
| {seq} | 連番・その他 | 連番。コピーするたびに増える |
| {seq:0000} | 連番・その他 | 桁を揃えた連番 |
| {seq+1} | 連番・その他 | 次の番号 + 1（範囲を書くときなど） |
| {guid} | 連番・その他 | GUID（小文字・ハイフンあり） |
| {guid:N} | 連番・その他 | GUID（ハイフンなし / B 波かっこ / U 大文字） |
| {random} | 連番・その他 | 1〜100 の乱数 |
| {random:1-6} | 連番・その他 | 範囲を指定した乱数（下限は負でもよい） |
| {{ | 連番・その他 | 波かっこ { そのもの（}} なら }） |
