# 連続コピー＆ペースト

アプリ A に並んでいる複数の値を先にまとめてコピーし、アプリ B へ同じ順番で貼り付けられます。
A と B のあいだを 1 件ごとに往復する必要はありません。

通常時の組み込み機能は、トレイメニューの「作業ツール」にまとまっています。
開始した作業モードだけがメニュー先頭へ移り、進捗と操作を表示します。
使わない機能は、設定画面の「アクションの表示」からメニューに出さないようにできます。

1. トレイメニュー →「作業ツール」→「連続コピー＆ペースト」
2. アプリ A で、移したい値を上から順にコピーする（`Ctrl+C` でも、右クリックの「コピー」でも、アプリのコピーボタンでも構いません）
3. アプリ B へ移動し、貼り付けたい場所で `Ctrl+V` する
4. 次の場所へ移動して `Ctrl+V` を繰り返す

最初の `Ctrl+V` で収集から貼り付けへ自動的に切り替わり、1 件目が入ります。
最後の値を貼り付けるとモードは自動終了します。

収集中のトレイメニューでは、現在の件数を確認できます。
「最後のコピーを取り消す」で直前の 1 件を外したり、
「収集を終えて貼り付けへ」で最初の `Ctrl+V` より前に収集を締め切ったりできます。
途中でやめる場合は「連続コピー＆ペーストをキャンセル」を選びます。

作業中は、開始した画面の右下に**進捗パネル**が表示されます。
表示やボタン操作で入力先のフォーカスを奪わないため、元のアプリでそのまま作業を続けられます。

- 収集中は、件数と最後にコピーした内容を表示します。「最後のコピーを取り消す」「貼り付けへ」をパネルから操作できます
- 「収集した内容を確認」を開くと一覧が表示され、貼り付け開始前に ↑ / ↓ で並べ替えたり、× で不要なコピーを削除したりできます。同じ文字列も別々のコピーとして扱います
- 並べ替えた後も「最後のコピーを取り消す」は、最後に収集したコピーを取り除きます
- 貼り付け中は、次に貼り付ける内容・何件目か・残り件数・進捗バーを表示します。一覧では送信済みの項目にチェックが付き、次の項目が強調されます
- 貼り付け開始後は順番の変更・削除はできません。完了・キャンセル・10 分間操作がない場合は、パネルも自動で閉じます
- コピー通知をオフにしていても、作業中の進捗パネルは表示されます

- 対象は**文字列としてコピーできるデータ**です。画像やファイルだけのコピーは追加しません
- 収集するのは、**キーやマウスを操作した直後に発生したクリップボード更新**だけです。ウィンドウの終了など、操作を伴わない更新通知は無視します
- どこまでを 1 件として集めるかは、設定画面の「連続コピーの設定」で選べます（→ 連続コピーで集める操作）
- **パスワード管理ソフトなど、コピー元が他のアプリでの保存を断っている内容は集めません。** どの設定でも同じです
- このアプリ自身がコピーした内容（トレイメニューの項目など）は集めません
- 同じ文字列を複数回コピーした場合も、別々の 1 件として順番を保ちます
- 順送りする貼り付け操作は `Ctrl+V` です。右クリックメニューの「貼り付け」や `Shift+Insert` では次へ進みません
- 収集内容はメモリ上だけに置き、設定ファイルや履歴には保存しません
- 10 分間コピーも貼り付けもなければ、モードを自動的に解除します
- 貼り付け直前にクリップボードを更新できなかった場合、その回の `Ctrl+V` を止めます。古い内容を誤って貼り付けないためです
- 作業モード中は、競合するコピー項目や別の作業ツールを無効にします。収集済みデータを暗黙に破棄しないためです

### 連続コピーで集める操作

Windows は「クリップボードが変わった」ことしか教えてくれず、
**誰がどうやってコピーしたかは分かりません。**
そのため、直前の入力操作からこのアプリが推測しています。
どこまでを 1 件として集めるかは、設定画面の「連続コピーの設定」で選べます。

| 選択肢 | 集まるもの | 集まらないもの |
| --- | --- | --- |
| **操作した直後のコピー**（既定） | `Ctrl+C`、右クリックの「コピー」、アプリのコピーボタン、アプリ独自のショートカット | 常駐している他のアプリが、操作していないあいだに自動で書き込んだ内容 |
| Ctrl+C のときだけ | `Ctrl+C` / `Ctrl+X` / `Ctrl+Insert` / `Shift+Delete` | 右クリックの「コピー」、アプリのコピーボタン |
| 変わったときは常に | クリップボードが変わったものすべて | （取りこぼしはありません） |

- 既定は「操作した直後のコピー」です。**この設定を持たない古い設定ファイルでも既定が入る**ため、
  以前のバージョンから引き継いだ場合も集まり方が変わります。
  従来どおりにしたい場合は「Ctrl+C のときだけ」を選んでください
- 余計なものが 1 件入ってしまったときは、「最後のコピーを取り消す」で外せます
- 連続コピー用の監視は、その作業モードの実行中だけです。「文字入力で自動展開」に合図を設定している場合は、別途その照合用に入力を監視します
