# クリップボードの内容を加工する

空行除外はトレイメニューの「作業ツール」に常設されます。
JSON の加工は、対象をコピーしたときだけ「この内容でできること」に表示されます。

| アクション | 場所 | 利用できるとき | 結果 |
| --- | --- | --- | --- |
| 空行を除外 | 作業ツール | 空、または空白文字だけの行を含む文字列をコピーしたとき | 空行だけを取り除く。残した行の CRLF / LF と末尾改行は維持する |
| JSONをMinify | この内容でできること | JSON のオブジェクトまたは配列をコピーしたとき | 不要な空白と改行を取り除いて 1 行にする |
| JSONを整形 | この内容でできること | JSON のオブジェクトまたは配列をコピーしたとき | 2 スペースのインデントと改行で読みやすくする |

処理結果はクリップボードへ戻るので、そのまま目的のアプリへ貼り付けられます。
JSON の入力ではコメントと末尾カンマも受け付けますが、出力時にはそれらを除いた標準 JSON へ正規化します。
使わないアクションは、設定画面の「アクションの表示」から個別に非表示にできます。
