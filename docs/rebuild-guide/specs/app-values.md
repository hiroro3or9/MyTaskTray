# 前面アプリの情報を差し込む

メニューを開く直前に作業していたアプリの名前とウィンドウタイトルを、そのままコピー文字列へ入れられます。
メニューを組み立てる時点では前面が MyTaskTray 自身に変わっているため、**開く操作を受け取った瞬間の情報**を
記録して使います。選択肢や複数入力が続く場合も、最初に記録した同じ情報を最後まで保持します。

```text
前面アプリ: code.exe
タイトル:    README.md - MyTaskTray - Visual Studio Code

[{app:name}] {app:title}
→ [code] README.md - MyTaskTray - Visual Studio Code
```

タイトルやアプリ名から一部だけを取り出す場合は、正規表現を `/` で囲んで書きます。
最初のキャプチャがあればその値、なければ一致全体を差し込みます。

```text
タイトル: Issue #4329 - ログイン画面 - Microsoft Edge

feature/issue-{app:title:/Issue #(\d+)/}
→ feature/issue-4329

タイトル: README.md - MyTaskTray - Visual Studio Code

{app:title:/^(.*?) - /}
→ README.md
```

- アプリ名は実行ファイル名から末尾の `.exe` を除いたものです
- 正規表現は 200 ミリ秒で打ち切ります
- 前面アプリを取得できない、タイトルが空、正規表現が不正、または一致しない場合は、
  差し込みを書いたまま残して問題に気付けるようにします
- 長いウィンドウタイトルは先頭 512 文字までを使います
- 設定画面のプレビューには、最後にメニューを開いたとき取得できた外部アプリを使います。
  まだ取得できていない場合は差し込みを書いたまま表示します
