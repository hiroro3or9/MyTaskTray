# 書式付きでコピーする

編集欄の右上にある「形式」で、コピーするときの見え方を選べます。

| やりたいこと | 形式 |
| --- | --- |
| 見出し・箇条書き・表を Word や Slack にきれいに貼りたい | **Markdown** |
| 文字色やスタイルなど、タグでしか書けないことをやりたい | **HTML** |
| 書式は要らない | そのまま（既定） |

**迷ったら Markdown です。** 記法が短く、エディタに貼っても読める文字列のままなので、
どちらの貼り付け先でも自然になります。

### 仕組み

Windows のクリップボードは 1 回のコピーで複数の形式を同時に載せられ、
**貼り付け先のアプリが自分の扱える形式を選びます。**
そのため 1 つの項目で貼り付け先を選びません。

**どの形式でもプレーンテキストは必ず載ります。** メモ帳やエディタには、常に書いたままの文字列が入ります。

たとえば `# {date:yyyy/MM/dd} 定例ミーティング 議事録` を Markdown 形式にしておくと:

| 貼り付け先 | 入るもの |
| --- | --- |
| Word / Outlook / Slack | 見出しとして書式が付く |
| メモ帳 / VS Code | `# 2026/08/05 定例ミーティング 議事録` がそのまま入る |

### Markdown の書き方

```markdown
# 見出し1        ## 見出し2
- 箇条書き       1. 番号付き
**太字**        *斜体*      ~~打ち消し~~
`コード`        リンク
- [ ] 未完了     - [x] 完了

| 列A | 列B |
| --- | --- |
| 値1 | 値2 |
```

行を空けると段落が変わります。
見出し・箇条書き・強調・リンク・コードのほか、表・脚注・打ち消し線・タスクリストにも対応しています。

### HTML の書き方

```html
<b>太字</b>  <span style="color:red">赤字</span>
<ul><li>項目</li></ul>
1行目<br>2行目
```

落とし穴が 2 つあります。

**1. 改行は `<br>` が必要です。**
書いた改行は HTML にとってただの空白なので、Word や Slack では行が変わりません。

```text
- 様
- 456
```

これを HTML 形式でコピーすると、メモ帳へは 2 行で入りますが、
Word・Outlook・Slack へは `- 様 - 456` と 1 行で入ります。
**貼り付け先によって結果が違う**ので、原因が分かりにくい種類の食い違いです。
箇条書きにしたいだけなら、`<ul><li>` を書くより**形式を Markdown にする**ほうが簡単です。

**2. タグを書かないと、ほぼ意味がありません。**
ただのテキストを HTML 形式にしても、そのままコピーするのと変わらないうえ、改行だけ壊れます。

### 差し込みとの組み合わせ

差し込み（`{date}` や `{input:名前}`、`{choice:…}`）は形式にかかわらず使えます。

HTML 形式では、**差し込まれた値だけ**が自動でエスケープされます。
自分で書いたタグはそのまま生きるので、`<b>{choice:担当:田中|佐藤}</b>` のような書き方ができます。
