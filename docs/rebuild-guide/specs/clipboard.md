# クリップボードの内容を差し込む

決まった形のうち一部だけが毎回変わる文字列は、変わる部分を `{clip}` にしておきます。

```
feature/AAA/ver1.0.0/ID-{clip}
```

1. 変わる部分（`4329`）を、チケット画面などからいつもどおりコピーする
2. トレイメニューからこの項目を選ぶ
3. `feature/AAA/ver1.0.0/ID-4329` がクリップボードに入る

貼り付け先で文字列を組み立てる必要がなくなり、操作は「コピー → クリック」だけになります。
メニューのツールチップには展開後の値が出るので、選ぶ前に結果を確認できます。

### 余計な文字を取り除く

コピー元に他の文字が混ざっていても、必要な部分だけを取り出せます。

```
クリップボード: ID-4329 ログイン画面が表示されない

feature/AAA/ver1.0.0/ID-{clip:digits}      → feature/AAA/ver1.0.0/ID-4329
feature/AAA/ver1.0.0/{clip:/ID-\d+/}       → feature/AAA/ver1.0.0/ID-4329
{clip:line}                                 → ID-4329 ログイン画面が表示されない
```

`digits` `line` `upper` `lower` `raw` `trim` 以外の書式は**正規表現**として扱い、最初に一致した部分を取り出します。
`ID-(\d+)` のようにかっこ（キャプチャ）を書くと、その中身だけが差し込まれます。
一致しなかった場合は `{clip:…}` と書いたままの文字列が残るので、意図しない結果に気付けます。

### 差し込み結果を置き換える

`{replace:元の値|検索文字|置換文字}` で、差し込み結果の一部をすべて置き換えられます。
「元の値」には `{clip}` だけでなく `{input:…}`・`{match:…}`や、別の `replace` を入れ子にできます。

```text
クリップボード: Hello World
{replace:{clip}| |-}                         → Hello-World

入力「URL」: https://example.com
{replace:{input:URL}|https://|}              → example.com

スマートアクションの値: feature/login
{replace:{match:value}|/|-}                  → feature-login

クリップボード: feature name/test
{replace:{replace:{clip}| |-}|/|-}           → feature-name-test
```

- 検索は大文字・小文字を区別し、一致箇所をすべて置換します
- 置換文字を空にすると削除できます
- 検索文字を空にはできません。誤って全文字の間へ挿入する動作を防ぐためです
- 検索文字と置換文字は差し込みとして展開せず、そのままの文字として扱います

正規表現で置換する場合は `{regexreplace:元の値|パターン|置換文字}` を使います。

```text
{regexreplace:{clip}|\s+|-}                  連続する空白を - にする
{regexreplace:{clip}|(\w+)-(\w+)|$2_$1}      foo-bar → bar_foo
{regexreplace:{clip}|(?i)cat|dog}            CAT / Cat / cat → dog
```

置換文字では `$1` `$2` の番号付きキャプチャと `${name}` の名前付きキャプチャを使えます。
大文字・小文字を区別しない場合は、パターンの先頭に `(?i)` を付けます。
正規表現は 200 ミリ秒で打ち切り、不正なパターン・タイムアウト・構文の不足があれば
差し込みを展開せず、書いたまま残します。

`|` は引数の区切りなので、検索文字・正規表現・置換文字に含める場合は `\|` と書きます。
正規表現の選択 `cat|dog` は `{regexreplace:{clip}|cat\|dog|pet}` のようになります。

| エスケープ | 意味 |
| --- | --- |
| `\|` | `|` |
| `\n` / `\r` / `\t` | 改行 / 復帰 / タブ |
| `\\` | `\` |
| `{{` / `}}` | `{` / `}` |

### クリップボードの日付

差し込みに `@clip` と書くと、**クリップボードの文字列を日付として読んで**起点にします。
日付をコピーしてメニューを選ぶだけで、書式の変換や前後の日付の計算ができます。

```
クリップボード: 2026/08/15

{date@clip:yyyyMMdd}       → 20260815
{date@clip:yyyy年M月d日}     → 2026年8月15日
{date@clip:ddd}            → 土
{date@clip+1w}             → 2026/08/22
{date@clip+1mo-1}          → 2026/09/14
{week@clip} {dow@clip}     → 33  6
```

`{month@clip}` `{year@clip}` `{monthend@clip}` など、日付から作られる差し込みはすべて使えます。

#### 読み取れる表記

まず**文字列全体**を次の表記として読みます。

`2026-08-15` / `2026/08/15` / `2026.08.15` / `20260815` / `2026年8月15日`
（月日は 1 桁でも構いません）

全体が日付でない場合は、**文中から最初の日付らしい並び**を取り出します。

| クリップボードの内容 | 読み取れる日付 |
| --- | --- |
| `リリース日: 2026/08/15 まで` | 2026/08/15 |
| `2026-08-15 14:30` | 2026/08/15（時刻は無視します） |
| `03-0000-0000` `090-1234-5678` | （なし。年が 4 桁でないため拾いません） |
| `2026-13-45` | （なし。存在しない日付のため） |
| `8/15` `15/08/2026` | （なし。年が先頭の 4 桁である必要があります） |

読み取れなかった場合、**トレイからのコピーは中止され**、「日付として読み取れません」と通知が出ます。
展開されなかった差し込みがそのまま貼り付けられてしまうのを防ぐためで、
クリップボードが空のときと同じ扱いです。設定画面のプレビューでは `{date@clip}` と書いたままが表示されます。

> `20260815` のような 8 桁の数字は日付として読みます。
> 8 桁の伝票番号などをコピーしている場合も日付になってしまいますが、
> これは区別のしようがないため、そのまま受け入れています。

> 地域設定によって `08/15/2026` を拾ったり拾わなかったりしないよう、
> 受け付ける表記は上に挙げたものだけに限っています。

> 正規表現に単独の `}` を書くことはできません（差し込みの終わりと区別できないため）。
> `\d{2,4}` のように `{` と `}` が対になっている書き方は問題ありません。

`{clip}` を含む項目を選んだときにクリップボードが空だと、コピーは行わず通知でお知らせします。
数値であれば `{calc:{clip}*1.1|#,##0}` のように計算式の中でも使えます。
