# カテゴリ装飾

同じ定義を設定画面、配置先Popup、QuickAdd、トレイで使う。色だけなら小さい色印、アイコンがあれば指定色のアイコン。色なしアイコンは#808080。未知アイコンは描かない。
ColorはTrim→大文字、#RRGGBB以外は空。IconはTrim、キーはOrdinal。リセットで色・アイコンを両方空にする。

| 値 | 表示名 |
| --- | --- |
| 空 | 色なし |
| #4F8EF7 | ブルー |
| #2A9D8F | ティール |
| #55A65A | グリーン |
| #D59618 | アンバー |

| #8B5CF6 | パープル |
| #D65A9E | ピンク |

アイコン字体はSegoe MDL2 Assets。アイコンなしだけYu Gothic UIの「—」。
