# スマートアクション

項目の「スマートアクション」を開いて表示条件を指定すると、その項目は通常の一覧には出ず、
現在のクリップボードが条件に合ったときだけ、メニュー先頭の「この内容でできること」に表示されます。
メニューを開くたびに現在の内容で判定し直します。

| 表示条件 | 表示されるとき |
| --- | --- |
| 常に表示 | 従来どおり通常のメニューに常に表示 |
| 文字列がある | 空白以外の文字列がコピーされている |
| 日付 | `2026-08-15` や `20260815` など、クリップボードの日付として読める |
| Web URL | `http://` または `https://` の URL |
| 数値 | クリップボード全体を数値として読める |
| JSON | JSON のオブジェクトまたは配列として読める |
| Windowsのパス | ドライブ文字または UNC で始まるパス |
| メールアドレス | メールアドレスの形に一致する |
| 正規表現 | 指定した正規表現に一致する |

判定で取り出した値は `{match:名前}` でコピー文字列に差し込めます。
どの条件でも元の文字列は `{match:value}`、正規表現では `{match:1}` などの番号付きキャプチャと
`{match:id}` などの名前付きキャプチャを使用できます。

```text
表示条件: 正規表現
正規表現: /issues/(?<id>\d+)
コピー文字列: feature/issue-{match:id}

クリップボード: https://example.test/issues/4329
→ feature/issue-4329
```

組み込み条件には次の追加値があります。

| 条件 | 値 |
| --- | --- |
| Web URL | `{match:scheme}` `{match:host}` `{match:path}` `{match:query}` |
| 数値 | `{match:number}` |
| Windowsのパス | `{match:name}` `{match:directory}` `{match:extension}` |
| メールアドレス | `{match:local}` `{match:domain}` |

正規表現が不正な場合は保存を中止して入力欄を表示します。照合は長時間メニューを止めないよう
200 ミリ秒で打ち切り、その場合は条件に一致しなかったものとして扱います。

### 複数行にまとめて適用する

「複数行にも適用する」にチェックを入れると、クリップボードから**一致するところをすべて拾い**、
その数だけコピー文字列を作って改行でつなぎます。
1 行ずつコピーして貼り付ける往復を繰り返す必要がなくなります。

```text
表示条件:     正規表現   ^(\w+)\t(\w+)$
コピー文字列: {match:2}-{match:1}

クリップボード（3 行）        コピーされる内容
  hoge01→hoge02               hoge02-hoge01
  hoge03→hoge04         →     hoge04-hoge03
  hoge05→hoge06               hoge06-hoge05
```

コピー文字列は 1 行だけコピーしたときと同じものを使います。書き足すことはありません。

#### 1 件が複数行にまたがる場合

**正規表現に改行を書くだけです。** 専用の書き方はありません。

```text
表示条件:     正規表現   ^(\w+)[\r\n]+(\w+)$
コピー文字列: {match:1}─{match:2}

クリップボード（4 行）        コピーされる内容
  hoge01                      hoge01─hoge02
  hoge02                →     hoge03─hoge04
  hoge03
  hoge04
```

照合は前の一致の終わりから続くので、1〜2 行目・3〜4 行目…と自然に組になります。
番号付き・名前付きのキャプチャも、1 行のときとまったく同じに使えます。

> **`^` と `$` は各行の先頭・末尾になります。** 複数行に適用するときだけ、
> 正規表現の複数行モードを自動で有効にしています。付けないと、1 行用に書いた
> `^…$` の項目がチェックを入れた瞬間に一致しなくなり、黙ってメニューから消えてしまうためです。

> **改行は `\n` に揃えてから照合します。** Windows のクリップボードの改行は `\r\n` ですが、
> 複数行モードの `$` は `\n` の直前でしか一致しないため、揃えないと
> 「行末に見えない `\r` があるせいで」ほとんど一致しません。
> パターンには `\n` だけを書けば足ります（`[\r\n]+` と書いても動きます）。
> 複数行にまたがる `{match:0}` の改行も `\n` になります

#### 条件の種類で切り方が変わります

| 表示条件 | 何を 1 件とするか |
| --- | --- |
| 正規表現 | クリップボード全体に繰り返し当て、**一致した箇所ごと**に 1 件（複数行にまたがれます） |
| それ以外（Web URL・日付・数値・メールアドレス・文字列がある） | **1 行**を 1 件 |

正規表現以外は「文字列全体がその形か」を見る判定なので、繰り返す先がありません。
そのため行で区切ります。URL が並んだ一覧をまとめて変換する、といった使い方はこちらです。

```text
表示条件:     Web URL
コピー文字列: feature/{match:host}

クリップボードに URL が 20 行 → 20 行ぶんの feature/… が一度に入る
```

#### 共通の決まり

- **条件に合わないところは飛ばします。** 見出し行や空行は自然に落ちます。
  行数と件数が合わなくなるため、通知には「(3 件)」のように**入った件数**を出します
- 1 件も一致しなければ、この項目はメニューに出ません
- 1 度に作る上限は 200 件です。超えた分は処理せず、ツールチップと設定画面でその旨をお知らせします
- 照合は**項目 1 つあたり 200 ミリ秒**で打ち切ります（1 件あたりではありません）。
  表示の判定はメニューを開くたびに走るため、量に比例してメニューが重くなるのを防いでいます
- 連番（`{seq}`）と時刻は 1 回のコピーにつき 1 つの値です。全件で同じ値になり、連番は 1 つだけ進みます
- ツールチップには件数と、先頭 1 件の展開結果を出します
  （全件を並べても 200 文字で切れて読めないため）
- 行ごとに照合する条件では、行の**末尾**の空白だけを取り除きます。
  先頭は残すので、1 列目が空のタブ区切りでも列がずれません
- **`{clip}` は 1 件ではなくクリップボード全体を指します。** 各件を指すのは `{match:…}` のほうです。
  `{clip}` を書くと全文がそのまま毎件に入ってしまうので、この設定と組み合わせるときは使わないでください

> **「常に表示」では選べません。** 表示条件が無いので区切る根拠がなく、
> メニューを組み立てるときにクリップボードも読んでいないためです。
> 行ごとに扱いたい場合は「文字列がある」を選んでください。

> **JSON 条件には使えません**（チェックは出ますが、意味がありません）。
> 整形済み JSON は複数行にまたがるため、行に切ると 1 行ずつが JSON として読めなくなります。
> 日付や Windows のパスも、全体を 1 件として見るほうが素直です。
