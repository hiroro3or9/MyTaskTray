# クリップボードをその場で項目にする

「これ、毎回打っているな」と気付いたときに、設定画面を開かずに項目を作れます。

1. 定型化したい文字列を、いつもどおりコピーする
2. トレイメニュー →「クリップボードを項目に追加...」
3. 名前と追加先を確認して Enter（初期値のままでも構いません）

追加先はトップレベルまたは既存カテゴリから選べるほか、新しいカテゴリ名も直接入力できます。
同じ起動中は直前に使った追加先を覚えます。項目は選んだ場所の末尾へ追加され、
並べ替えや差し込みへの書き換えはあとから設定画面で行えます。

- 前後の空白と改行は取り除きます（途中の改行はそのまま残ります）
- **`{` `}` はそのままの文字として登録します。** JSON やソースコードをコピーした場合に、
  一部が差し込みとして評価されてしまうのを防ぐためで、内部では `{{` `}}` のエスケープに直しています。
  差し込みとして使いたい場合は、追加後に設定画面で `{` `}` に直してください
- すでに同じ内容の項目がある場合は、その項目の名前を知らせて追加しません
- クリップボードが空、または文字列以外のときはメニュー項目が押せなくなります
- 設定ファイルを読み込めていない状態でも押せません（追加して保存すると、読めなかった設定を失うため）

設定画面を開いている場合は、ファイルではなく**設定画面の一覧に追加**されます。
設定画面は開いた時点の内容を編集しているため、ファイルへ書いても保存の時点で消えてしまうためです。
「追加」ボタンで作ったのと同じ未保存の状態になるので、保存すると確定します。
