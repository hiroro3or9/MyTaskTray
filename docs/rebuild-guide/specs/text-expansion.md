# 文字入力で自動展開

入力欄に `;sig` などの合図を打ち終えると、合図を消して登録した本文を貼り付けます。

1. 設定画面で通常のテキスト項目を選び、「文字入力で自動展開」を開きます。
2. 呼び出し文字列に `;sig` などを設定して保存します。空欄にすると無効です。
3. 別のアプリで **IME をオフ**にして合図を入力し、展開を待ちます。

- 合図は `;` と半角英数字・`_`・`-` で合計 2～32 文字。大文字小文字を区別します。
- 本文は日本語・複数行・日付などの差し込みにも対応します。展開後の本文はクリップボードにも残ります。
- 同じ合図や、先頭が別の合図と一致する設定（`;sig` と `;signature`）は保存できません。
- 書式付き項目、入力／選択肢付き項目、クリップボード条件付き項目、行ごとの一括適用は対象外です。アプリ条件は適用します。
- 設定画面やメニューを開いている間、Swap コピーや作業モード中は停止します。
- Backspace・カーソル移動・クリック・入力先の変更・5 秒を超える入力間隔で照合をやり直します。
- カーソル直前の文字を Windows のアクセシビリティ機能で確認できる入力欄が対象です。確認できない欄、パスワード欄、読み取り専用欄では展開しません。
- 合図の直後に続けて文字を入力した場合も、誤置換を避けるため展開を取り消すことがあります。
- 管理者権限のアプリや独自の貼り付け処理を持つ入力欄など、動作しない場合があります。
- 日本語を**合図**にする IME 確定後の展開は未対応です。
