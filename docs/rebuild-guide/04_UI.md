# 外観設計

## 方針

単位はWPF DIP。画面の数値・要素構造はspecs/ui-index.mdから必要な画面のみ読む。
元XAMLを同梱せず、画面要素と属性・状態を設計表へ変換している。表中のBindingは表示を結び付ける先の意味を示す。実装で同じ名前を使うと対応が容易。
新たに元画面を操作して比較した資料ではない。Windowsのネイティブ描画やフォント差は同条件で最終確認する。

## 設定画面

Title=MyTaskTray の設定、980×800、最小840×560、CenterScreen、Yu Gothic UI 13。
ヘッダー余白18,16,18,0、見出し「メニュー構成」18 SemiBold、説明Hint。
本体余白18,14,18,0。左330/最小250、Splitter10、右*/最小400。左Cardの内側10、右編集16。

```text
メニュー構成 / 説明
┌ 検索・アウトライン ┐ ┌ 表示名・配置先             ┐
│ 通常メニュー       │ │ 自動展開 / 条件 / アプリ   │
│  カテゴリ→項目     │ │ 本文・形式・差し込み挿入   │

通知、ホットキー、アクション、連続コピー、スプリント、フォルダー
                                  キャンセル / 保存して閉じる
```

項目行は名前SemiBold、本文11.5/上余白2、長文省略。バッジ順は形式→連番→入力→スマート→複数行→アプリ→カテゴリ、該当時だけ。カテゴリバッジ最大幅90。
区切り線行20/中央ラベル10.5、カテゴリ配下字下げ27。
カテゴリ見出しは幅3×高さ22の色線、22×22折畳みボタン、14のアイコン、名前、件数。
カテゴリ選択時は専用編集へ切替。区切り線/未選択は説明。
本文は複数行/Tab入力、Consolas系。Popupで各設定を編集。タブ式へ変えない。
保存132幅、キャンセル104幅。狭幅時の配置は現行の改善課題なので、再現で勝手に配置を改善しない。表示差は記録する。

## テーマ

specs/colors.mdのキーをLight/Darkで一致させDynamicResource使用。ControlTemplateの設定はspecs/ui-styles.md。
HKCU Software/Microsoft/Windows/CurrentVersion/Themes/Personalize の AppsUseLightTheme=0なら暗色。他は明色。
HKCU Software/Microsoft/Windows/DWM のAccentColorをAABBGGRRとして取得。不可なら#0F6CBD。UserPreferenceChangedで再適用。
輝度=(.299R+.587G+.114B)/255。暗色で<.35なら白へ.38、明色で>.72なら黒へ.30混合。
Hover/Pressedはアクセントを暗色なら白、明色なら黒へ.14/.28混合。OnAccentは輝度>.55で#141414、他は白。
Selectedは面色へ暗色.78/明色.86混合。各成分Math.Round。色辞書はMergedDictionaries先頭、アクセントはApplication.Resourcesで上書き。
タイトルバーはDwmSetWindowAttribute20→失敗時19。
トレイはWinForms標準ライト、暗色は背景#2B2B2B/文字#F1F1F1/hover#3D3D3D/枠#515151/無効#808080。チェック背景とチェック線を両方描いて視認性維持。
